## 1. 조사 범위와 한계

### 읽은 양
| 구분 | 수량 |

### 한계 (이 문서를 읽을 때 반드시 감안할 것)
1. **이미지는 읽지 못했다.** 생활 백서 가이드 대부분이 스크린샷 중심(flex, 메일 서명, 회의실 예약, 복합기, 음향기기, 심야교통편 등)이다. 텍스트로 풀린 절차만 요약했고, "그림에만 있는 단계"는 빠졌을 수 있다.
2. **민감 페이지는 본문을 열지 않았다.** `급여, 4대보험, 퇴직금` · `백패커 평가보상제도 안내` · `비상연락망 (개인&셀)` 은 검색 스니펫으로 주제만 확인했다. `스톡옵션` 은 범위 한정 검색에서 결과가 0건이어서 **주제를 확인하지 못했다**(권한 문제인지 색인 문제인지 불명).
3. **1단계 아래 자식 페이지는 선별해서만 열었다.** 열지 않은 것: 캘린더 Q&A 4개, 연차 관련 하위 4개(연차 설명·연차 사용 계획서·유결 신청·휴일근무/대체휴무), 복리후생 하위 11개(경조사, 명절선물, 반려동물 동반출근, 랜덤런치, 구성원쿠폰, 우산 대여, 비상용 생리대, 정부지원제도, 헬스케어 패키지, 쾌적한 사옥, 장기근속포상), 가이드북 하위 3개, 인수인계 패키지 하위 양식 4개와 대장, Wi-Fi 문서가 링크하는 세부 가이드(무작위 MAC 해제, NAC 인증, DLP 설치, 히든 SSID 연결), Forticlient VPN 가이드 본문, 법인 카드 대여 및 사용 가이드 본문, 복합기 드라이버 설치, flex 전자계약 가이드.
4. **제목만 기록한 페이지**(지시에 따름): Archive, 1:1 notes, 타운홀 미팅 2.0, 맛집 지도. 그 외 시간상 열지 못한 페이지: Backpackr Standard, Thanks My Colleague 2.0, 동환식당, 비즈니스 매너, Backpackr Growth Committee, 구성원 고충처리 프로세스, 찾아오시는 길.
5. **truncated / 알 수 없는 블록**: `백패커의 초보 여행자를 위한 가이드북` 은 `truncated: true`(알 수 없는 블록 1개 — Tour guide 별칭 블록으로 추정). 생활 백서 루트, Wi-Fi, 그룹 메일, 지인추천, 퇴직 프로세스에 별칭(alias) 블록이 있어 그 대상은 표시되지 않았다.
6. **검색은 키워드 검색이다.** "찾지 못함"은 "없음"이 아니라 "이 검색어로는 안 나옴"이다. 특히 SSH 키, 장비 대여, 소프트웨어 라이선스는 다른 이름으로 존재할 수 있다.
7. **Flex 워크플로우 자체는 볼 수 없다.** 문서들이 "Flex 워크플로우에서 신청"으로 끝나는 경우가 많은데, 양식의 실제 항목·결재선·현재 존재 여부는 Notion에서 확인할 수 없다.
8. 모든 페이지가 Notion 검증 상태 `unverified` 이다. 최종 수정일은 참고치이며 내용의 정확성을 보증하지 않는다.

### 3-1. 사내 와이파이 세팅
- **위치**: `사내 네트워크 이용하기(Wi-Fi)` — 본체는 `IT Security / 정보보안 / 사내 인프라 구성`, 생활 백서와 Tour guide에서 링크.
- **절차 요약**:
  1. 업무용 SSID에 연결하고 비밀번호 입력(문서에 비밀번호 기재됨. 붙여넣기 실패 시 직접 입력).
  2. macOS 15 이상은 "무작위 MAC 주소" 해제(별도 가이드).
  3. 처음 연결하면 인터넷이 안 되거나 특정 페이지로만 이동 → 사내 인증 포털에서 상태 확인.
  4. 안내 메시지에 따라 조치: 백신 설치 / NAC Agent 설치 / MAC 주소 인증 / G-Suite 인증.
  5. **사용자 인증은 매달 1일 초기화** → 매달 재인증.
  - 망 3종: 업무용, 모바일 테스트용(히든 SSID, 스테이지 접속), 게스트용(신청 없이 인터넷만, 사내 시스템 접근 불가).
- **품질 메모**: 상단 본문은 `BPK_IAP`, 아래 QnA는 `BPK_IAP_20F` 로 SSID 표기가 다르다. 테스트망의 Flex 전자결재 절차는 취소선 처리됐는데 대체 절차 설명이 없다. Wi-Fi 비밀번호와 담당자 개인 연락처가 평문으로 있다. 같은 문서가 VPN·소프트웨어 신청·시스템 계정 신청까지 겸하고 있어 "와이파이 문서"라는 제목으로는 찾기 어렵다.

### 3-2. SSH 키 발급
- **전사 표준 문서를 찾지 못했다.** 검색된 조각:
  - `비개발자를 위한 Bitbucket 사용 가이드` (IT Security, 2026-09-16) — 개인 PC는 **HTTPS + 브라우저 SSO(Git Credential Manager)** 로 인증하며 별도 토큰·키 발급이 필요 없다고 안내. 서버/자동화는 API Token, **App Password는 폐지**. 계정은 flex `Bitbucket 사용신청/삭제 및 Repo 권한신청`.
  - 텀블벅 프론트엔드 업무 매뉴얼의 `git` (2026-10-18) — ssh-keygen(ed25519)·ssh-agent 등록 명령. 팀 한정.
  - Search/Recommend `새로운 bitbucket Repository 생성 가이드` (2026-05-22) — Bitbucket 개인 설정의 SSH keys 메뉴에서 키 추가.
  - `ec2 ssh 접근을 위한 rsa키 발급 요청` (2020, Deprecated 폴더), `[BE] 서버 ssh 접속 가이드` (Archive) — 과거 자료.
  - 아이디어스 클라이언트셀 `Bitbucket App password 적용 방법` (2026-04-06) — 위 "App Password 폐지" 안내와 상충.
- **핵심 문제**: "SSH 키 발급"이 (a) Bitbucket 접속용 개인 키 등록인지, (b) 서버 접속용 키를 DevOps가 발급해 주는 것인지 문서상 구분이 없다. (a)는 본인이 생성·등록하는 것이라 "발급"이 아니고, 현재 공식 안내는 SSH 대신 SSO다. 에이전트가 답하려면 **먼저 무엇을 위한 키인지 되물어야 하며**, (b)의 현행 절차는 Notion에서 확인되지 않았다(Slack #g_cell_devops 확인 필요).

### 3-3. AI API 키 신청
- **위치**: `백패커팀 / AI 활용 가이드 & 자료 모음 / AI API키 지원 - 챗GPT, Gemini, Claude` (https://app.notion.com/p/29c1f5a7134480b581d8f2ba63895d87, 2026-09-18). **생활 백서에는 링크가 없다.**
- **절차 요약**: Flex 워크플로우(문서에 직접 링크)에 신청 목적을 적어 신청 → 월 한도가 걸린 API 키 수령. 대상은 전 구성원, 인당 1개 키(사용량 추적), 관리자 일괄 결제. 한도 상향은 효용 확인 후 정식 구매 승인 절차 필요. 용도 외 사용·외부 유출 금지.
- **혼동 주의 — 비슷한 제도가 둘이다**:
  - `AI API키 지원` = API 키(소액 한도), 위 워크플로우.
  - `AI 유료툴 지원 안내` (https://app.notion.com/p/35d1f5a71344809e9924c0461cf9f05d, 2026-05-20) = Claude 등 **구독형 요금제** 지원. flex `AI 유료 Tool 지원 신청/삭제` 승인 → 회사 계정으로 로그인 → 셀 운영비 카드 등록 → 고위드에 용도 `AI 지원`·정해진 메모 형식으로 기록. 퇴사 전 구독 해지 필수(퇴직 프로세스와 연결).
  - 추가로 `백패커 AI Tool 지원 신청자 대상 필수 확인`(2026-10-28), `API 키 탈취 방지 시스템`(2026-05-27), 구버전 `전사 유료 AI툴 지원 안내 (구버전)`(Archieved)이 있다.
- **품질 메모**: 내용은 명확하고 최신. 다만 어떤 제공사(챗GPT/Gemini/Claude) 키를 어떻게 고르는지, 발급까지 걸리는 시간, 키 전달 방식은 문서에 없다.

### 3-4. Jira 발급
- **전용 전사 문서 없음.** 확인된 근거:
  - Wi-Fi 문서의 "사내 개발/디자인 소프트웨어 사용 신청방법" 토글 — Flex 전자결재로 신청 가능한 목록에 `Jira/Confluence` 포함(JetBrains, Sentry, Postman, Parallels, LucidChart, Figma, C4D, Sketch, Zeplin, RemoteCall과 함께). 발급되면 Slack으로 계정 정보 전달.
  - Tour guide — "flex 통해 소프트웨어 계정/권한 신청하기" 한 줄.
  - 셀별 온보딩 문서 3건이 **flex 워크플로우 `Jira, Confluence 계정 신청/삭제`** 를 명시: IDUS Backend `1. 계정·권한 신청`(2026-11-16, "미완" 표시), Search/Recommend `신규 입사자 계정 신청 워크플로우 및 필요 항목 정리`(2026-05-22), 텀블벅 FE `Jira`(2026-10-18).
- **절차 요약**: Flex → 워크플로우 → `Jira, Confluence 계정 신청/삭제` 작성. 사이트는 사내 Atlassian 클라우드.
- **품질 메모**: 비개발 직군이 찾아갈 입구가 없다. 신청 가능한 소프트웨어 목록이 "와이파이 문서" 안에 묻혀 있다.

### 3-5. 택배 신청

- **절차 요약**:

### 3-6. 가족돌봄휴가 신청
- **위치**: `생활 백서 / Work-Family Balance / 다양한 제도` DB의 `가족 돌봄 휴가` 행 (https://app.notion.com/p/d4501ec955f7450a877b37ef7eb5f6c7).
- **절차 요약**: 대상은 가족(부모, 자녀, 배우자, 배우자의 부모)의 질병·사고·노령으로 돌봄이 필요한 구성원. 연간 10일, **무급**(유급 휴가 소진 후 사용 권장). 신청은 **Flex → 휴가 → 가족 돌봄 휴가**.
  - 참고: `가족 돌봄 휴직` 은 연 90일(최소 30일 연속, 분할 가능), 무급, Flex 워크플로우 `휴직 신청`.
- **품질 메모**: 요건과 신청 경로는 있으나 증빙 서류, 사전 신청 기한, 승인자는 없다. flex 가이드에 "포상휴가·대체휴무 외 휴가는 증빙 첨부"라는 일반 규칙만 있다. `휴가 신청 프로세스` 페이지의 `연차 외 휴가 정책` DB에는 가족돌봄휴가가 **없다** — 휴가를 찾는 사람이 먼저 보는 페이지에서는 발견되지 않는다. 검색하면 코로나19 시기 공지 사본 `가족돌봄 휴가 or 휴직 안내`(근로감독 자료 폴더)가 같이 나온다.

2. **Jira/Confluence 등 소프트웨어 계정 신청** — 비개발 직군용 안내 없음. Flex 워크플로우 전체 목록(카탈로그)이 Notion 어디에도 없다.
3. **소프트웨어 라이선스(어도비, MS Office 등) 신청·회수** — 현행 문서 없음.
4. **장비 대여·추가 지급·교체·고장** — `최신장비지급` 은 입사 시 지급 원칙만 있다. 태블릿 같은 공용 장비 대여 절차 없음.
5. **생활 백서에 링크되지 않은 핵심 문서** — 택배/등기/퀵, AI API 키·유료툴, 구매/자금집행 가이드, 법인카드 가이드, VPN 가이드. 재직자가 가장 자주 찾을 만한 문서들이 생활 백서 밖 최상위에 흩어져 있다.
6. **가족돌봄휴가** — 휴가 안내 페이지의 DB에 누락. 증빙·기한 설명 없음.
7. **정기 주차 신청 접수 경로** — 정책은 있으나 어디서 신청하는지 없음.
8. **계정·접근 문제 대응**(공용 계정 비밀번호 초기화, 인터넷 차단 해제, 외부 협력사 Slack 초대, 주 52시간 초과 시 근태 처리 등) — Slack #_qna_genie 최근 글에 실제로 올라오는 유형인데 대응 문서를 찾지 못했다(이 항목은 검색을 따로 돌리지 않았으므로 "미확인"에 가깝다).

### 5-4. 에이전트 설계에 직접 영향을 주는 관찰
- **신청 경로의 대부분이 Flex 워크플로우다.** 문서는 "어떤 워크플로우를 쓰는지"까지만 알려 준다. 에이전트가 답할 핵심 정보는 결국 `주제 → 워크플로우 이름(+직링크) → 승인자 → 담당 셀` 표이며, 이 표의 정본이 현재 없다.
- **담당 창구는 소수로 수렴한다**: 프렌즈셀(인사·총무·복리후생·주차), 재무회계셀(카드·경비), DevOps셀/IT 보안(네트워크·계정·VPN·Bitbucket), 법무셀(공문·등기), 그리고 범용 창구 #_qna_genie.
