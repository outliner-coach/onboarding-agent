## 2. 채널 운영 방식

### 이미 동작 중인 Q&A 봇이 있음 (중요)

- **`genie`(자칭 "백지니") 봇**이 거의 모든 최상위 글에 **10~20초 안에 스레드로 자동 답변**한다. 질문뿐 아니라 "식대초과 입금했습니다", "마지막 약 복용했습니다" 같은 보고 글에도 붙는다.
- 답변 형식: 본문 → `✅ / ❌` 리액션으로 정확도 피드백 요청 → **출처(과거 Slack 대화 또는 Notion 페이지 링크 + 연월)** → **담당자/담당 그룹 태그**("내용이 다르면 정정 부탁").
- 지식 등록 방식: 사람이 스레드에서 **`@genie (답변등록) 내용`** 으로 정답을 등록하면 이후 유사 질문에 재사용. 프렌즈셀·DevOps셀 담당자가 실제로 이 방식으로 등록 중.
- 관찰된 한계
  - 지식 원천이 대부분 **과거 Slack 대화**(출처 표기가 2024-08 ~ 2026-10 대화). Notion 문서를 직접 근거로 삼는 경우가 적다.

## 4. 사용자 예시 주제 6개 — 절차 요약

### 4-1. 사내 와이파이 세팅 — **답 있음 (가장 잘 정리됨)**

- SSID 구분: `BPK_IAP`(사내 업무망, 인증 필요) / `BPK_GAP`(게스트성 망) / dev·qa 앱 테스트는 IAP가 아닌 별도 SSID에서 수행(스레드에서 TAP/GAP 표기가 혼재 → **확인 필요**).
- `BPK_IAP` 사용 조건 4가지
  1. 백신(Bitdefender) 설치 — 보통 설치된 상태로 지급
  2. NAC agent 설치 — IAP에 연결한 상태에서 사내 NAC 포털의 agent 페이지에서 OS별 설치
  3. NAC 장비 인증 — NAC 포털에서 MAC 값 확인 후 `nacpass` 버튼으로 장비 MAC 인증
  4. NAC 구글 인증 — NAC 포털에서 `인증` 버튼으로 회사 구글 계정 인증 (**매월 1일 재인증 필요**, 알림봇이 공지)
- macOS Sequoia(15.x) 이상: Wi-Fi 설정의 **'비공개 Wi-Fi 주소(무작위 MAC)'를 반드시 끔**.
- 자주 막히는 지점: 포털 인증서 경고 화면(advanced로 진행), 포털 새로고침이 동작하지 않음(탭을 닫고 다시 열기), nacpass에 입력한 MAC 오타, 유선 연결 시 라우팅 우선순위 문제(스크립트 재실행), 느릴 때는 재부팅/재연결.

## 6. 문서가 없어 매번 사람에게 묻는 것으로 보이는 공백 영역

1. **"무엇을 어디에 신청하는가" 통합 지도** — 툴·권한마다 창구(flex 워크플로우 / 프렌즈셀 / DevOps셀)가 다르고, 신청 후 채널에 다시 알려야 하는지도 불명확. 가장 반복되는 질문 유형.
2. **SSH 키·개발 환경 초기 세팅** — 채널에 답이 전혀 없음. Bitbucket 권한 → 키 등록 → VPN → DB 접근(방화벽 등록에 IP·MAC 필요, Jira 티켓 필요)까지 이어지는 흐름이 스레드에 조각나 있음.
3. **AI 관련 절차** — 유료 구독 신청은 워크플로우가 있으나, API 키 발급(종류별), 팀 워크스페이스 합류, 어떤 플랜을 결제하는지, 추가 계정 정책, 사용량 수집 도구 설치는 매번 담당자가 개별 안내.
4. **휴가 증빙 기준** — 가족돌봄·건강검진·예비군 공가·병가(시간 단위 가능 여부) 등 "어떤 증빙을 언제 내는가"가 개별 DM으로 처리됨.
5. **주 52시간 초과·핫워커 인정 시간** — 같은 질문이 한 달 사이 여러 번 반복(초과 시 출근 등록 불가, 인정 시간 계산, 근무시간 보정).
6. **택배 전체 흐름** — 시트 사용법, 픽업 요일, 재출력, 포장 용품 위치가 스레드에만 존재.
7. **장비 정책** — 대여 가능 품목·재고, 노트북 교체 주기, 고장 시 절차, 신규 구매 요청 경로(flex에 구매 워크플로우가 없어 Notion으로 진행한다는 언급).
8. **VPN(모바일 포함)·볼트워든 초기 설정** — 설치 중 오류 문의가 반복.
9. **슬랙 운영 규칙** — 외부인 초대 방법, 유저그룹 추가, 채널 공개 전환, 퇴사자 소유 워크플로우·앱 처리.
10. **퇴사·인수인계 시 자산 이전** — 캘린더 일정 소유자, 구글 시트 소유권, 슬랙 앱·워크플로우, 그룹메일 소유자. 담당자들도 가이드북 필요성을 언급.
11. **텐바이텐 합류 구성원 특수 사항** — 기존 도메인 계정(MS 365, 피그마 공용계정), 무선전화기, 어드민 비밀번호 등 이관 과도기 질문.
12. **담당자 찾기** — "세금계산서 담당자가 누구?", "리더 멘션용 그룹이 뭐?" 같은 사람·그룹 탐색 질문.

## 7. 온보딩 에이전트 설계에 주는 시사점 (조사자 해석)

- **기존 genie 봇과의 역할 구분이 선결 과제**. 같은 채널에서 같은 질문에 답하는 봇이 이미 있고, 지식 등록 루프(`답변등록`, ✅/❌)도 돌고 있다. 새 에이전트가 대체인지, 다른 표면(1:1 대화형, 단계별 안내)인지, genie의 지식을 공유하는지 정해야 한다.
