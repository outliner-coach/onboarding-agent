# 담당 셀과 문의 채널

기준일: 2026-11-17. 개인 이름은 적지 않는다. 담당자가 바뀌어도 셀과 채널은 유지되기 때문이다.

## 기본 창구

- **`#_qna_genie`**: 어디에 물어야 할지 모를 때의 범용 창구. 글을 올리면 `genie` 봇이 먼저 답하고, 담당 셀이 스레드에서 처리한다.
- 관례: "지니님 안녕하세요"로 시작한다. 담당 셀은 `:확인중:` → `:완료_:` 리액션으로 상태를 표시한다.
- flex 워크플로우를 올린 뒤 채널에 "신청했습니다, 확인 부탁드립니다"라고 다시 알리는 경우가 많다.

## 영역별 담당

| 영역 | 담당 셀 | 문의 경로 |
| --- | --- | --- |
| 네트워크(Wi-Fi, NAC, VPN, 인터넷 차단 해제), AD 계정, 보안 프로그램 | DevOps셀 | `#_qna_genie` |
| Jira, Confluence, Bitbucket, AWS, 개발 도구 계정 | DevOps셀 | flex 워크플로우 신청 후 `#_qna_genie`. Bitbucket 사용 문의는 `#g_cell_devops`의 `@cloud-engineer` |
| 망분리 시스템, 외부 저장매체 사용, 테스트 단말기 업무망 연결, 보안성 검토 | IT Security | 결재 서식 신청 후 `#_qna_genie` |
| 모바일 테스트 단말기 대여 | 프렌즈셀(총무) 또는 QA셀. CTO 직속 조직이라고 안내한 답변도 있음 | `#_qna_genie`에 요청하고 `모바일 장비 대여 및 반납 신청서` 작성 |

| 총무, 시설, 비품, 택배, 명함, 장비 대여·교체 | 프렌즈셀 | `#_qna_genie` |
| 슬랙 관리(외부인 초대, 유저그룹, 채널 전환) | 프렌즈셀 | `#_qna_genie` |
| 소프트웨어 라이선스(어도비, MS Office 등) | 프렌즈셀 | flex 워크플로우 신청 후 `#_qna_genie` |
| 인사, 근태, 휴가, 휴직, 복리후생 | 프렌즈셀(HR) | `#_qna_genie`. 개인 사정이 담긴 내용은 HR 담당자 DM |

| AI 툴(유료 지원, API 키, 사용량) | 프렌즈셀(AI 담당) | flex 워크플로우 신청 후 `#_qna_genie` |

| 심야 교통편 계정, 원팀 예산 기준, 도서 구매, 교육 지원 | 프렌즈셀 | `#_qna_genie` |

## 확인이 필요한 것

- 셀별 Slack 유저그룹 핸들(멘션용)은 `@cloud-engineer`, `@dba` 외에는 수집하지 못했다.
- 프렌즈셀 전용 문의 채널이 따로 있는지 확인하지 못했다.

어떤 대상이 어느 창구인지는 [guides/accounts-and-access.md](guides/accounts-and-access.md)에 표로 정리돼 있다.
