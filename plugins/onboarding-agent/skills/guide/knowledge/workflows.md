## flex 워크플로우가 아닌 신청 경로

| 대상 | 경로 |
| --- | --- |
| 택배, 퀵, 등기 | 구글 시트 ([guides/parcel.md](guides/parcel.md)) |
| DB 접근 권한 | Jira "DevOps셀" 프로젝트, 이슈 유형 "RDS 유저 접근권한 생성/변경/삭제 (DCL)" |
| 심야 교통비 | Notion `심야 교통 이용신청서` |
| 고위드 카드 지출(원팀 예산, 업무용 택시비, 오프라인 100만원 이하 업무비) | 고위드 앱 또는 웹에 영수증 첨부 |
| Datadog | `#g_cell_devops`에 초대 요청 |
| ArgoCD, Grafana | 신청 없이 AD 계정(사번)으로 로그인 |
| 휴가(가족 돌봄 휴가 포함) | flex 휴가 신청 화면 (워크플로우 아님) |
