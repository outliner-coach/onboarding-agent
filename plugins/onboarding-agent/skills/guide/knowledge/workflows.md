# 결재 서식(워크플로우) 목록

기준일: 2026-11-17.

> 결재(워크플로우)는 2027년 1월 예정으로 flex에서 friends-erp로 옮겨 간다. **전환 전까지는 flex가 정식이다.** 전환 후에는 friends-erp의 「결재」 메뉴에서 같은 이름의 서식을 고른다. 자세한 내용은 [guides/friends-erp.md](guides/friends-erp.md).

## 서식을 찾는 방법

| 시점 | 방법 |
| --- | --- |
| 지금 (flex) | [flex 워크플로우 작성 화면](https://flex.team/workflow/write/templates)에서 서식 이름으로 검색. 아래 "flex 직링크"에 있는 서식은 링크로 바로 연다 |
| 전환 후 (friends-erp) | 메뉴 「결재」 → 「새 문서 작성」 → 서식 선택 |

공통 규칙
- 결재선은 자동으로 채워진다. 보통 1차 조직장(셀 리더) 다음에 서식별 담당 승인자가 붙는다.
- 조직장이 부재 중이면 셀 내 다른 사람을 지정해 대결 결재를 받는다.
- 일부 서식은 안내문에 "특정 담당자를 참조에 직접 추가"하라고 적혀 있다. 서식 상단 안내문을 읽고 따른다.
