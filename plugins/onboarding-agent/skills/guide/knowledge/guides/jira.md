# Jira·Confluence 계정

## 한 줄 요약

flex 워크플로우 `Jira, Confluence 계정 신청/삭제`를 올리면 DevOps셀이 Atlassian에 초대한다.

## 절차

1. [flex 워크플로우 작성 화면](https://flex.team/workflow/write/templates)을 연다. (Flex 로그인 → 워크플로우 → 문서 작성하기)
2. 검색창에 `jira`를 입력해 **`Jira, Confluence 계정 신청/삭제`** 양식을 고른다.
3. 아래 항목을 채워 올린다. 조직, 이름, 이메일은 자동으로 들어간다.
   - 계정 생성/삭제: `생성`
   - 신청 종류: `Jira`, `Confluence` 중 필요한 것. Confluence를 쓰지 않으면 Jira만 고른다
   - 신청사유
   - 서식 상단 안내문에 참조로 추가하라고 적힌 담당자가 있으면 참조에 넣는다
4. 승인되면 DevOps셀이 초대한다. 계정 정보는 Slack으로 전달된다.
5. 초대 메일이 오지 않거나 링크가 만료됐으면 `#_qna_genie`에 재초대를 요청한다.

## 발급 이후 요청

아래는 관리자 권한이 필요하다. `#_qna_genie`에서 DevOps셀에 요청한다.

- 표시 이름(닉네임) 변경
- 프로젝트 또는 Confluence 스페이스 생성
- 복직자 계정 복원, 퇴사자 계정 정리

## 같은 방식으로 신청하는 도구

flex 워크플로우로 신청하는 개발·디자인 도구: JetBrains, Sentry, Postman, Parallels, LucidChart, Figma, C4D, Sketch, Zeplin, RemoteCall, Bitbucket, AWS 콘솔, Redash. 양식 이름은 [workflows.md](../workflows.md) 참고.

## 확인이 필요한 것

- 양식 직링크를 확보하지 못했다. 이름으로 검색해야 한다.
- 전사 공식 문서가 없다. 근거는 결재 서식 자체와 셀별 온보딩 문서, Slack 답변이다.
- 결재선은 1차 조직장 다음에 담당 승인자 1명이 자동으로 붙는다. 조직장이 부재 중이면 셀 내 다른 사람을 지정해 대결 결재를 받는다. 초대까지 걸리는 시간은 확인하지 못했다.
- Jira 커넥터가 연결되지 않아 Jira 쪽에서 직접 확인하지 못했다.
