# 총무·법무 서비스

## 한 줄 요약

명함과 법무 요청(공문, 날인, 계약 검토, 인감증명서)은 **결재 서식**으로 신청한다. 복합기는 **드라이버를 직접 설치**해 쓴다. 시설 고장은 **`#_qna_genie`에 위치와 증상**을 올리면 프렌즈셀이 접수한다.

## 창구 한눈에 보기

| 하려는 일 | 어디에 | 처리 |
| --- | --- | --- |
| 종이 명함 만들기, 추가 제작 | 결재 서식 `회사 명함 발주 신청` | 프렌즈셀 |
| 이미지 명함(jpg) 받기 | `#_qna_genie`에 요청 | 프렌즈셀 |
| 복합기 인쇄·스캔 설정 | 직접 설치 (아래 B) | 안 되면 `#_qna_genie` |
| 계약서 검토와 날인 | 결재 서식 `계약검토요청` | 법무셀 |
| 공문 검토, 계약서가 아닌 문서에 날인 | 결재 서식 `인감날인요청(공문 포함)` | 법무셀 |
| 법인인감증명서 | 결재 서식 `법인인감증명서 요청` | 법무셀 |
| 통신 서비스 이용 증명원 | 결재 서식 `통신 서비스 이용 증명원 요청` | 문의는 `#_qna_genie` |
| 화장실, 조명, 냉난방, 문, 누수, 복합기 고장 | `#_qna_genie`에 제보 | 프렌즈셀 |

결재 서식은 지금 [flex 워크플로우 작성 화면](https://flex.team/workflow/write/templates)에서 이름으로 찾는다. 2027년 1월 예정으로 friends-erp로 옮겨 간다([friends-erp.md](friends-erp.md)).

## A. 명함

### 종이 명함

대상 (서식 안내문, 2026-11-17 기준)
- 사무실 근무 구성원: 정규직, 계약직
- 현장 근무 구성원: Staff 직급 이상
- 추가 발주: 재고가 떨어졌거나 떨어질 예정일 때, 조직개편·인사발령으로 꼭 필요할 때, 전화번호나 이메일이 바뀌었을 때

절차
1. flex에서 `회사 명함 발주 신청` 서식을 연다.
2. 안내문의 항목을 채운다. 이름, 휴대폰 번호, 메일 주소는 비상연락망 정보와 달라진 것이 있을 때 적는다.
3. 서식 안내문에 참조로 추가하라고 적힌 담당자가 있으면 참조에 넣고 보낸다.
4. 조직장(소속 리더) 승인 → 발주 담당자 승인 → 제작 → 배송 순으로 진행된다. 발주 전에 담당자가 명함 파일을 공유하니 내용을 확인해 준다.

알아 둘 것
- 신청일로부터 **최대 15영업일**이 걸릴 수 있다. 쓸 날짜가 정해져 있으면 여유 있게 신청한다.
- 급하면 서식을 올린 뒤 `#_qna_genie`에 필요한 날짜를 알린다. 프렌즈셀이 일정을 당겨 준 사례가 있다.
- 최소 주문 수량은 100장이다(등록 답변, 원본 2026-07).
- 메일 주소는 회사 메일(backpac.kr)로만 제작한다. 다른 주소가 필요하면 프렌즈셀에 문의한다.

### 이미지 명함

미팅 뒤 명함을 이미지로 보내야 할 때 쓴다.

1. `#_qna_genie`에 "이미지 명함(jpg) 요청드립니다"라고 올린다.
2. 프렌즈셀이 명함 이미지 파일을 DM으로 보내 준다.

## B. 복합기와 팩스

복합기 (Notion `복합기 드라이버 설치하기`, 2026-04-29 수정)

| 위치 | 종류 | 모델 |
| --- | --- | --- |
| 20층 OA부스 | 컬러 | Sindoh D450 |
| CS룸 | 컬러 | Sindoh D450 |
| 20층 복도 맨 끝 창가 | 흑백 | Sindoh N501 (설치하면 N500으로 표시될 수 있다) |

처음 설치할 때
1. Sindoh 다운로드 센터에서 모델을 연다: [D450](https://www.sindoh.com/ko/customer/total-search-result.php?key_word=D450), [N501](https://www.sindoh.com/ko/customer/total-search-result.php?key_word=N501)
2. 운영체제(Windows 10 x64 또는 Mac)에 맞는 `PCL6 Driver (빠른설치)` 또는 `Mac Driver`를 내려받는다.
3. 압축을 풀고 setup을 실행한다.
4. `네트워크 IP 주소` 칸에 쓸 복합기의 IP를 넣는다. 복합기별 IP는 [Notion 원문](https://app.notion.com/p/ee59360d9fa54265babe8222ba04b890)에 있다. 여기에는 적지 않는다. 원문 스크린샷 속 IP는 무시하고 본문에 적힌 값을 쓴다.
5. 인쇄할 때 프린터로 `SINDOH D450/CM` 또는 `Sindoh N501(또는 N500)`을 고른다. 목록에 없으면 같은 이름으로 수동 추가한다.

복합기 IP가 바뀌어 인쇄가 안 될 때 (Notion `복합기/팩스 이용가이드`, 2026-01-14 수정)
- Windows: `프린터 및 스캐너` → 해당 프린터 → `프린터 속성` → `포트` 탭 → 쓰는 포트를 고르고 `포트 구성` → `프린터 이름 또는 IP 주소`에 새 IP 입력 → 확인
- Mac: 브라우저에서 `http://localhost:631`을 연다 → `Printers` → 해당 프린터 → `Administration` 메뉴에서 `Modify Printer` → `Continue`를 눌러 `Connection` 단계로 간다 → 주소의 IP를 새 IP로 고친다 → `Continue` → `Save Changes`. 중간에 macOS 관리자 이름과 암호를 물을 수 있다. 이 주소가 안 열리면 터미널에서 `cupsctl WebInterface=yes`를 실행한 뒤 다시 연다.

Windows에서 인쇄가 멈출 때
- 시작 메뉴에서 `서비스` 검색 → `Print Spooler` → 서비스 상태 `중지` → `시작` → 시작 유형 `자동` → 다시 인쇄

팩스
- 20층 팩스 번호는 [Notion 원문](https://app.notion.com/p/f06471b53b944fda90a44ec2b094fc30)에 있다.
- 팩스 보내는 법, 스캔해서 메일로 보내는 법은 문서에 글로 적혀 있지 않다. 막히면 `#_qna_genie`에 묻는다.

고장과 소모품
- 용지 걸림, 토너 부족, 스캔 오류는 `#_qna_genie`에 어느 복합기인지와 증상을 올린다. 프렌즈셀이 조치하거나 수리 기사를 부른다. 기사가 올 때까지는 다른 복합기를 쓴다.

## C. 법무 요청: 공문, 날인, 계약 검토, 인감증명서

### 어떤 서식인가

| 상황 | 서식 | 직링크 (flex) |
| --- | --- | --- |
| 계약서를 검토받고 날인까지 받는다 | `계약검토요청` | [작성](https://flex.team/workflow/write/templates?template-key=265cb636af7f4ca89def7b4dd910ec76&im=write) |
| 공문을 보낸다, 계약서가 아닌 문서에 날인받는다 | `인감날인요청(공문 포함)` | [작성](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=fb2d393f57fc4d94b86a82fc86e34461) |
| 법인인감증명서가 필요하다 | `법인인감증명서 요청` | flex에서 이름으로 검색 |

- `계약검토요청`은 검토와 인감 날인을 한 번에 진행한다. 날인 요청이나 서류 요청을 따로 올리지 않는다.
- 계약서가 아닌 문서에 날인이 필요하면 `인감날인요청(공문 포함)`을 쓴다.

### 공문 검토와 날인

1. flex에서 `인감날인요청(공문 포함)` 서식을 연다. 제목은 `인감날인요청(공문 포함)_문서명_제출처` 형식이다.
2. 서식에 첨부된 `[표준] 공문 서식` 파일을 내려받아 초안을 쓰고 첨부한다. 서식 안의 파란 글자가 작성 안내다.
3. 법무 담당자에게 요청할 내용을 본문에 적는다. 예: "법인인감으로 날인해야 하고 법인인감증명서 1부도 필요하다(사용인감 안 됨)", "날인받을 문서를 첨부할 수 없어 따로 전달하겠다"
4. 승인자와 참조자는 기본으로 설정돼 있다. 관련 담당자나 연관 셀이 있으면 1단계 참조에 추가한다.
5. 보낸다. 급한 건은 보낸 뒤 법무 채널에 알린다.

꼭 지킬 것
- **날인이 필요 없는 공문도 실무자가 그냥 써서 보내지 않는다.** 날인이 없어도 효력이 생길 수 있으므로 반드시 검토를 요청한다.
- **우편, 팩스, 메일로 공문이나 내용증명을 받으면 임의로 처리하지 않는다.** 바로 법무 담당자에게 전달한다.
- 회사 레터헤드 양식은 따로 없는 것으로 안내됐다. 표준 공문 서식을 쓴다(2026-06 법무셀 답변).

증명서류 발급(강의경력증명서, 실적 증명, 행사 참가확인서 등)도 `인감날인요청`으로 올린다. 아래를 적는다(법무셀 등록 답변, 2026-09).
- 받는 사람 정보(예: 강사의 성명, 주소)
- 확인해 줄 내용(강의 경력, 실적, 강의 시간 등)
- 종이로 필요한지, 스캔본이면 되는지

### 계약 검토

먼저 확인할 것
- **계약서가 필요한 거래인가**: 거래 기간이 1개월 이상이거나 유지보수 조건이 필요한 거래는 계약서가 필수다. 연간 거래금액 100만원 이하는 생략할 수 있다(Notion `구매/자금집행 가이드`).
- 금액과 관계없이 계약서를 써야 하는 것: 인건비, 저작권 등 지식재산권 귀속, 경영에 관한 계약, 개인정보 처리, 유지보수, 임대차, 보안 관련 계약. 해당하는지 애매하면 법무 채널에 묻는다.
- **사전승인 대상인가**: 대상이면 `사전 승인 요청` 문서에 법무를 참조로 넣는다. 사전승인이 끝나야 계약서에 날인할 수 있다. 검토만 먼저 받고 싶으면 사전승인 전에도 요청할 수 있다.
- 표준 계약서 파일은 Notion [표준 계약서/서약서](https://app.notion.com/p/dbc6e773d69844f888003c873a62cc94)에 있다(구매, 용역, MOU, 비밀유지, 변경계약, 개인정보 처리위탁 등).

절차
1. flex에서 `계약검토요청` 서식을 연다. 제목은 `계약검토요청_문서명_계약상대방명` 형식이다.
2. 상대방과 협의한 계약 조건, 실무자 검토 의견, 요청 사항을 적는다. 함께 받아야 할 서류가 있으면 여기에 쓴다. 예: "인감증명서와 법인등기부등본 각 1부", "법인인감 날인 필요". 아직 정해지지 않은 내용은 "미정"이라고 쓴다.
3. 첨부한다: 사업자등록증, 견적서(발주서), 계약서 초안 등. 상대방이 개인이면 성명만 쓰고 신분증은 첨부하지 않는다. 논의한 슬랙이나 노션 링크도 넣는다. 첨부가 5개 이상이면 zip으로 묶는다.
4. 승인·참조를 설정한다.

   | 경우 | 1단계 | 2단계 |
   | --- | --- | --- |
   | 기본 | 셀 리더(승인), 법무(참조) | 법무(승인) |
   | 유관 부서가 있다 | 유관 부서나 담당자를 참조에 추가 | |
   | 법인인감이 필요하다 | 법인인감 담당자(재무회계셀)를 참조에 추가 | |
   | 개인정보 관련 내용이 있다 | 개인정보 담당자를 참조에 추가 | |
   | C레벨 승인이 필요하다 | | C레벨을 승인에 추가 |

5. 보낸다. 법무가 검토하고, 끝나면 날인본을 문서에 첨부해 완료 처리한다.

자주 막히는 곳
- **셀 리더가 직접 작성한다** → 1단계 승인자가 자동으로 한 단계 위(C레벨)로 잡힌다. C레벨 승인이 필요 없으면 승인자에서 지운다.
- **승인·참조자를 잘못 넣었다** → 취소하고 다시 작성해야 한다. 본문 내용은 보내기 전까지 고칠 수 있다.
- **법무에 공개하기 어려운 문서에 법인인감이 필요하다** → 메일로 법인인감 날인을 요청하는 예외 경로가 있다. 방법은 [Notion 원문](https://app.notion.com/p/0ea7eec6dd554cdca8ca100b0dd6cc51)의 "주요 QnA"에 그림으로 있다.
- **같은 표준 전자계약을 자주, 많이 보낸다** → 매번 서식을 올리는 대신 모두싸인 권한을 받아 직접 발송하도록 법무와 협의할 수 있다.
- **담당자 이름**: 참조에 넣을 법인인감 담당자와 개인정보 담당자의 이름은 Notion 원문과 서식 안내문에 있다. 여기에는 적지 않는다.

### 법인인감증명서

1. flex에서 `법인인감증명서 요청` 서식을 작성한다.
2. 조직장 승인이 끝나면 법무 담당자가 증명서를 전달한다.
3. 위임장과 함께 내야 하면 위임장에도 법인인감 날인이 필요하다. 위임장 날인을 어느 서식으로 올리는지는 안내문에 없다. 계약서가 아닌 문서의 날인은 `인감날인요청(공문 포함)` 서식이다.

### 법무 문의 채널

- 법무 문의는 `#g_cell_legal`에 한다(프렌즈셀 확인, 2026-11-17).
- Notion `공문 검토 및 날인 요청하기`에는 `#project_genie_legal`이 적혀 있지만 쓰지 않는다.
- 슬랙 태그는 `@legal`.

## D. 통신 서비스 이용 증명원

문자 발송 증빙 등으로 통신 서비스 이용 증명원이 필요할 때 쓴다.

1. flex에서 `통신 서비스 이용 증명원 요청` 서식을 연다.
2. 적는다: 소속 부서, 요청 형태(종이, pdf 등), 제출처, 가입 및 착신 번호(쓰는 전화기에 적혀 있다), 용도.
3. 문의는 `#_qna_genie`.

발급일로부터 1개월만 유효하다.

대상 예: 에어컨·냉난방기, 조명, 문과 손잡이, 화장실, 누수, 복합기.

- 건물 중앙 냉난방은 18시에 꺼진다.
- 덥거나 추우면 회사가 따로 설치한 천장형 에어컨의 온도와 바람 세기를 조절한다. 리모컨은 해당 라인 끝 복도 쪽 책상에 있다. 안 보이면 `#_qna_genie`에 묻는다.

조명
- 자리가 어두우면 레일등 추가를 요청할 수 있다. `#_qna_genie`에 요청하면 프렌즈셀이 확인하고 레일등을 전달한다(Notion `쾌적한 사옥`, 2024-09 수정).

장비 고장(PC, 모니터, 키보드)은 [equipment.md](equipment.md), 인터넷이 안 되는 문제는 [wifi.md](wifi.md)를 본다.

## 확인이 필요한 것

- 20층 팩스 번호는 회사 번호지만 이 가이드에 옮기지 않고 원문을 가리켰다. 팩스 송신과 스캔 메일 전송 조작법은 문서에 그림만 있거나 없다.
- 복합기 가이드는 20층만 다룬다. 19층은 같은 문서에서 "과거 내용"으로 분리돼 있다.
- 신규 입사자의 첫 명함이 자동으로 제작되는지, 본인이 서식을 올려야 하는지 확인하지 못했다. Notion의 명함 문서는 모두 Archive나 옛 업무 보드에 있어 근거로 쓰지 않았다.
- `회사 명함 발주 신청`과 `법인인감증명서 요청`의 flex 직링크는 확인하지 못했다.
- 명함 소요 기간이 서식 안내문은 "최대 15영업일", 등록 답변은 "최대 약 15일"이다. 안내문을 따랐다.
- 사업자등록증 사본, 통장 사본, 법인등기부등본처럼 날인이 필요 없는 법인 서류를 어디에 요청하는지 문서를 찾지 못했다. 계약 건이면 `계약검토요청`의 요청 사항에 적는다.
- 사용인감과 법인인감 중 무엇을 찍는지의 기준은 문서에 없다. 서식에 필요한 인감을 적으면 법무가 판단한다.
- `계약 검토 및 인감 날인`의 작성 예시는 그림과 동영상이라 읽지 못했다.
- `[필독] 모두의 배려가 필요한 공용 공간`(흡연구역, 분리수거, 화장실 등 공용 공간 에티켓)은 열람하지 못했다.
- 시설 이상 제보 등록 답변의 원본 대화는 2024년 10월이다. 2026년 9~11월 채널에서 같은 방식으로 처리되는 것은 확인했다.
