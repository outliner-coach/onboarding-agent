# friends-erp

## 한 줄 요약

근태·휴가·결재가 flex에서 friends-erp로 옮겨 갈 예정이다. **지금은 QA 기간이라 정식 기록은 계속 flex다.**

## 지금 어디에 신청해야 하나

| 시점 | 휴가·출퇴근·결재의 정식 기록 |
| --- | --- |
| 정식 전환 전 (현재) | **flex**. friends-erp에 남긴 것은 연습용이고 정식 전환 전날 모두 지워진다 |
| 정식 전환 후 | **friends-erp**. flex에는 내지 않는다 |

- 정식 전환은 2027년 1월 예정이다. 서버를 사내 AWS로 옮기는 작업 때문에 늦어질 수 있다. 날짜가 확정되면 따로 공지된다.
- 휴가, 근태, 결재 질문에 답할 때는 **flex 기준으로 안내하고**, 전환 예정이라는 사실을 한 줄 덧붙인다.
- 사용자가 friends-erp에서 하는 방법을 물으면 아래 내용을 안내하되, QA 기간에는 flex에도 내야 한다고 알려 준다.

## 접속

- 주소: friends-erp.vercel.app → 「Google(@backpac.kr)로 로그인」. PC와 휴대전화 모두 된다.
- AWS 이전 후에는 주소가 바뀔 수 있다.
- 실제 인사 정보가 든 시스템이다. 화면 캡처를 회사 밖에 공유하지 않는다.

## friends-erp에서 하는 방법

### 휴가 (메뉴 「휴가」, `/leave`)

지금 flex에서 신청하는 방법은 [leave-request.md](leave-request.md)에 있다.

1. 「휴가 개요」에서 남은 휴가를 본다.
2. 연차 카드나 휴가 종류 카드를 누르면 신청 창이 열린다. 신청 창에 어느 휴가에서 얼마나 차감되는지 나온다.
3. 승인되면 내 구글 캘린더에 「휴가」 일정이 생긴다. 일정에 휴가 종류는 적히지 않는다.
4. 취소는 「사용한 기록」에서 신청 철회 또는 휴가 취소하기. 취소하면 캘린더 일정도 사라진다.

- 동료에게는 휴가 여부와 날짜·시간만 보이고 종류는 보이지 않는다. 리더는 「팀 휴가」에서 범위 안 팀원의 휴가 종류와 잔여를 본다.
- 「남은 휴가가 부족합니다」가 뜨면 ERP의 연습 기록 기준으로 막힌 것이다. QA 기간에는 flex에 낸다.

### 결재 (메뉴 「결재」, `/approvals`)

1. 「새 문서 작성」에서 서식을 고른다. flex 워크플로우 서식과 같게 만들어져 있다.
2. 결재선은 셀 리더 → 유닛 리더 → C레벨 순으로 자동으로 채워진다. 지출 문서는 지출 구분과 금액에 맞는 권장 결재선이 안내된다.
3. 문서에서 승인, 반려, 회수, 공유, 복제를 한다. 반려 사유는 댓글로 남기고, 댓글은 슬랙 DM으로 알림이 간다.

- QA 기간에는 인사팀이 고른 서식만 열려 있다. 연습 결재도 결재자에게 실제 슬랙 알림이 간다.
- flex의 기존 결재 문서는 2026년 9월 초까지만 옮겨져 있다. 나머지는 정식 전환 때 옮긴다.

### 근태 (메뉴 「내 근태」, `/attendance/me`)

지금 flex 기준의 근태 규칙은 [attendance.md](attendance.md)에 있다.

- 출근·퇴근은 **사무실 네트워크(Wi-Fi)에서만** 기록된다. 휴게는 어디서나 된다.
- 오늘·어제 기록은 그날 하루 상세에서 바로 고친다. 그보다 지난 기록은 수정 신청을 낸다.
- 외근, 출장, 휴일 근무는 「외근·출장 등록」에서 신청한다.
- 주 52시간에 닿으면 퇴근은 52시간이 찬 시각까지만 기록되고 근무 등록·수정 신청이 막힌다. 주 52시간 계산에는 실제 근무시간만 들어가고 휴가 시간은 더하지도 빼지도 않는다.

### 에이전트 연결 (메뉴 「에이전트 연결」, `/agent`)

- 개인 토큰을 만들면 Claude 같은 AI 도구가 내 권한 안에서 일을 돕는다. 선택 기능이다.
- 할 수 있는 것: 결재 서식과 문서 조회, 결재 초안 작성(기존 문서를 본뜬 복제 포함), 내 휴가와 근태 조회, 휴가 초안 작성, 동료의 휴가 여부 조회(종류는 안 보임).
- 상신을 허용한 토큰이면 추가로: 결재 상신과 회수, 휴가 신청과 취소, 댓글. 내 이름으로 확정되고 나에게 알림이 온다.
- 할 수 없는 것: 승인, 반려, 공유, 결재선 정정, 출퇴근 기록, 근태 신청.
- 짧은 시간에 문서를 아주 많이 읽거나 상신·취소를 아주 많이 하면 토큰이 자동으로 폐기된다.
- 발급할 때 「상신·휴가 신청·휴가 취소까지 허용」을 고를 수 있다. 조회와 초안만 맡길 거라면 끄고 발급한다.
- 토큰은 내 이름으로 동작한다. 쓰지 않는 토큰은 「내 토큰」에서 바로 폐기한다.

## 내 정보가 틀릴 때

프로필의 인사 정보(이름, 연락처, 소속, 직무)는 인사팀만 고칠 수 있다. 틀린 곳은 공지에 안내된 문의 창구로 알린다.

## 확인이 필요한 것

- 휴가 종류와 한도, 증빙 필수 여부는 [leave-types.md](leave-types.md)에, 결재 서식 97개는 [workflows.md](../workflows.md)에 정리했다. 종류별 증빙 서류, 유급·무급, 결재선은 확인하지 못했다.
- 전환 후에는 [workflows.md](../workflows.md)의 flex 직링크를 쓸 수 없다. friends-erp에서 서식을 바로 여는 링크 형식은 확인하지 못했다.
- 정식 전환일이 확정되지 않았다.
