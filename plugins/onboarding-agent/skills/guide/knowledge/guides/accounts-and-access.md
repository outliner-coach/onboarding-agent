# 계정·권한 신청 창구

## 한 줄 요약

무엇에 대한 권한인지에 따라 창구가 다르다. **툴과 시스템 계정은 결재 서식으로**, **슬랙·그룹메일·드라이브 폴더는 `#_qna_genie`에서 프렌즈셀에**, **네트워크와 보안 프로그램은 DevOps셀에** 요청한다.

## 먼저 물어볼 것

무엇에 대한 계정이나 권한인지 모르면 묻는다. 대상 이름만 알면 아래 표에서 창구가 정해진다.

## 창구 한눈에 보기

## A. 결재 서식으로 신청하는 것

찾는 방법
- 지금: [flex 워크플로우 작성 화면](https://flex.team/workflow/write/templates)에서 서식 이름으로 검색한다.
- 2027년 1월 예정 전환 후: friends-erp → 「결재」 → 「새 문서 작성」. [friends-erp.md](friends-erp.md) 참고.

공통으로 알아 둘 것
- 대부분 `신청/삭제` 겸용 서식이다. 권한이 필요 없어지면 같은 서식에서 `삭제`를 골라 올린다.
- 신청사유를 구체적으로 쓴다. 서식 안내문이 요구하는 항목은 보통 소속 셀, 구글 계정, 신청사유다.
- 결재선은 1차 조직장 다음에 담당 승인자가 자동으로 붙는다. 조직장이 부재 중이면 셀 내 다른 사람을 지정해 대결 결재를 받는다.
- 서식 상단 안내문에 참조로 추가하라고 적힌 담당자가 있으면 참조에 넣는다.
- 올린 뒤 `#_qna_genie`에 "신청했습니다, 확인 부탁드립니다"라고 남기는 관행이 있다.

### 아르바이트(크루) 계정

`아르바이트 사내 계정 생성 및 접근 권한 요청`을 현업 담당자가 올린다. 슬랙과 노션보다 많은 권한이 필요할 때 쓴다.
- 구글 계정, 슬랙 멀티 채널, MS Office는 유료 라이선스라 꼭 필요한 경우에만 고른다.
- 슬랙 단일 채널과 노션 게스트 계정은 무료다.
- 흐름: 현업 담당자 작성 → 셀·유닛 리더 승인 → 프렌즈셀 인재영입 담당이 계정 세팅 정보 기재 → 프렌즈셀 총무 담당이 처리 후 승인

## B. `#_qna_genie`에서 프렌즈셀에 요청하는 것

서식이 없다. 채널에 글을 올리면 프렌즈셀이 스레드에서 처리한다.

| 요청 | 글에 넣을 것 |
| --- | --- |
| 슬랙 채널에 외부 업체 담당자 초대 | 채널 이름, 초대할 사람의 이메일 |
| 슬랙 유저그룹에 사람 추가 | 유저그룹 이름, 추가할 사람 |
| 그룹메일에 사람 추가·제거, 관리자 권한 | 그룹메일 주소, 대상 계정, 필요한 권한(구성원, 관리자, 소유자) |
| 구글 공유 드라이브 폴더 권한 | 폴더 링크, 필요한 역할(뷰어, 편집자, 콘텐츠 관리자), 사유. 프렌즈셀이 폴더 성격을 보고 판단해 부여한다 |
| 구글 계정 비밀번호 초기화 | 대상 계정. 기존 비밀번호를 알면 직접 바꿀 수 있다. 분실했거나 잠겼을 때만 요청한다. 초기 비밀번호는 DM으로 받고, 로그인하면 변경 안내창이 뜬다 |
| 공용 계정 로그인 정보 | 어떤 계정이 왜 필요한지. 계정 정보는 관리하는 셀이 DM으로 전달한다 |

채널에 비밀번호나 계정 정보를 직접 쓰지 않는다. 요청만 올리고 정보는 DM으로 받는다.

## C. `#_qna_genie`에서 DevOps셀에 요청하는 것

- 인터넷 차단 해제, NAC 인증 문제 — [wifi.md](wifi.md)의 절차를 먼저 확인한다. 해결이 안 되면 OS와 막힌 단계를 적어 올린다
- VPN: 계정은 입사할 때 사번 계정으로 발급된다. 사용법은 Notion `Forticlient VPN 사용법`. 설치나 로그인 오류는 채널에 올린다
- 보안 프로그램(볼트워든 등) 권한
- Jira·Confluence 표시 이름 변경, 프로젝트·스페이스 생성 — [jira.md](jira.md)

## D. Jira 이슈로 신청하는 것

DB 접근 권한은 결재 서식이 아니라 Jira "DevOps셀" 프로젝트에 이슈 유형 "RDS 유저 접근권한 생성/변경/삭제 (DCL)"로 올린다. 운영(Prod) 계정에는 조회 권한만 나온다. 데이터를 고쳐야 하는 업무라면 설명에 사유를 쓴다. 문의는 슬랙 `@dba`.

## 권한을 반납할 때

- 쓰지 않게 된 툴은 같은 서식에서 `삭제`로 올린다.
- 휴직할 때는 `휴직자 계정 휴면전환 및 권한 회수 신청서`, 퇴사할 때는 `퇴직서류 작성`에서 계정과 권한이 회수된다.
- AI 유료 툴 구독은 퇴사 전에 직접 해지한다.

## 확인이 필요한 것

- `#_qna_genie` 봇의 등록 답변은 "구글 드라이브·문서 권한은 flex 워크플로우로 신청"이라고 한다. 그런데 결재 서식 목록에 드라이브 권한 서식이 없고, 실제 사례는 채널 요청으로 처리됐다. 이 가이드는 실제 사례를 따랐다.
- 그룹메일을 새로 만드는 방법: Notion `그룹 메일 설정하기`(2024-03)는 구글 그룹스에서 직접 만든다고 하지만, 최근 채널에서는 프렌즈셀에 요청한다. 직접 만들 수 있는지 확인이 필요하다.
- 서식별 담당 승인자와 처리 기간은 확인하지 못했다.
- 슬랙 채널 공개 전환, 유저그룹 신설 같은 슬랙 운영 규칙은 문서를 찾지 못했다.
- 노션 워크스페이스 권한과 게스트 초대 창구는 확인하지 못했다.
- 서식 목록은 조회한 계정의 권한으로 보이는 것이다. 일반 구성원에게는 일부가 보이지 않을 수 있다.
