# AI API 키와 AI 유료 툴

## 먼저 물어볼 것

비슷한 제도가 둘이다. 어느 쪽인지 확인한다.

- **API 키**: 구글 시트 AI 함수, 직접 만든 스크립트나 서비스에 AI 기능을 붙일 때 → A
- **유료 툴 구독**: Claude, ChatGPT 같은 서비스의 유료 요금제를 쓰고 싶을 때 → B

## A. AI API 키 신청

**한 줄 요약**: flex 워크플로우에 신청 목적을 적어 올리면 월 한도가 걸린 API 키를 받는다.

- 신청: [flex 워크플로우 바로가기](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=1d0873c8b3484a41b84d3dac66f48748)
- 대상: 백패커 전 구성원. 업무 용도의 테스트라면 누구나 신청할 수 있다.
- 지원: 인당 월 10달러 상한이 원칙. 인당 키 1개를 발급해 사용량을 추적한다. 결제는 관리자가 일괄 처리한다.
- 대상 모델: ChatGPT, Gemini, Claude

유의사항
- 모델마다 과금 수준이 다르다. 불필요한 비용이 나가지 않게 쓴다.
- 신청한 용도 외 사용과 외부 유출은 금지다.
- 한도가 부족하면: 업무상 효용이 확인된 경우 사용 추이를 보고 한도를 올릴 수 있다. 이 경우 정식 구매 집행 승인 절차가 필요하다.
- 먼저 Google AI Studio의 무료 Gemini API 키로 실험해 보는 방법도 있다.

## B. AI 유료 툴 지원 (구독)

**한 줄 요약**: flex `AI 유료 Tool 지원 신청`을 올리면 프렌즈셀 담당자가 승인하고 자금집행을 요청한다.

- 신청: [AI 유료 Tool 지원 신청](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=e91cc55fde604c4fb23e4803fdfa2365)
- 승인 후 절차(회사 계정 로그인, 카드 등록, 고위드 기록 방식)는 Notion [AI 유료툴 지원 안내](https://app.notion.com/p/35d1f5a71344809e9924c0461cf9f05d)를 따른다.
- 퇴사 전에는 구독을 해지해야 한다.
- 회사 계정으로 유료 구독 중이면 사용량 수집 크롬 확장 설치가 필수라는 Slack 안내가 있었다. 신청자 필수 확인 문서를 함께 본다.
