# 가족돌봄휴가

## 한 줄 요약

flex 휴가 신청에서 `가족 돌봄 휴가`를 골라 신청한다. 연간 10일, 무급이다.

## 내용

| 항목 | 내용 |
| --- | --- |
| 대상 | 가족(부모, 자녀, 배우자, 배우자의 부모)이 질병, 사고, 노령으로 돌봄이 필요해 휴가를 원하는 구성원 |
| 기간 | 연간 10일 |
| 급여 | 무급. 유급 휴가를 먼저 쓰고 난 뒤 사용하는 것을 권장 |
| 신청 | Flex → 휴가 → 가족 돌봄 휴가 |

## 시스템 전환 예정

휴가 신청은 2027년 1월 예정으로 flex에서 friends-erp로 옮겨 간다. 전환 전까지는 flex에 신청한다. 전환 후 신청 방법은 [friends-erp.md](friends-erp.md)의 휴가 항목을 본다. friends-erp에는 `가족돌봄`이라는 종류로 들어가 있고, 연간 한도 10일에 증빙 첨부가 필수로 설정돼 있다. Notion 문서의 일수와 같다.

## 증빙

증빙 첨부는 필수다. 다만 **어떤 서류를 내야 하는지는 표준 답이 없다.** friends-erp에도 서류 안내문이 없고, `#_qna_genie`의 HR 답변은 "사유에 따라 필요한 증빙이 달라 확인 후 개별 안내"였다.
어떤 서류가 필요한지 추측해서 말하지 않는다. 신청 전에 HR 담당자에게 확인하도록 안내한다.

가족의 건강 상태 같은 개인 사정은 공개 채널에 쓰지 않아도 된다. HR 담당자에게 DM으로 문의할 수 있다고 알려 준다.

## 더 긴 기간이 필요하면

**가족 돌봄 휴직**이 따로 있다. 연 90일(최소 30일 연속, 분할 가능), 무급. 결재 서식 `일반휴직 신청서`로 신청하는 것으로 보인다(Notion에는 `휴직 신청`으로 적혀 있다). 신청 전에 리더, 프렌즈셀과 사전 협의가 필요하다. 휴직 기간에는 급여와 복리후생이 적용되지 않는다.

## 확인이 필요한 것

- 2025-05 근무제도 개편 FAQ도 "연차를 다 썼고 가족 돌봄이 필요하면 가족돌봄휴가를 쓴다"고 안내한다.
- 근거 문서의 최종 수정일이 2022-05-13이다. 일수와 조건이 지금도 같은지 HR 확인이 필요하다.
- 어떤 증빙 서류가 인정되는지, 사전 신청 기한, 승인자가 문서에 없다.
- 휴가를 찾을 때 먼저 보게 되는 `휴가 신청 프로세스 및 관련 제도 안내` 페이지의 휴가 목록에는 이 휴가가 빠져 있다.
- 휴직 내용은 Notion 원문을 직접 읽지 않고 조사 요약으로만 확인했다.
