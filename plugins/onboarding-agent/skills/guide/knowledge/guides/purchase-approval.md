# 구매와 자금집행

## 한 줄 요약

거래처에 돈을 보내거나 온라인으로 결제하려면 문서를 두 번 올린다. **사기 전에 `사전 승인 요청`**, **받은 뒤에 `자금집행` 문서**다. 계좌이체는 매주 수요일에 나간다.

## 먼저 물어볼 것

- 무엇에 쓰는 돈인가: 일반업무비, 마케팅비용, 상품제작·매입 중 어디인가. 결재선이 다르다
- 금액이 얼마인가: 한 번 사는 것인가, 매달 내는 것인가
- 어떻게 지급하나: 국내 계좌이체, 해외 송금, 온라인 카드결제 중 무엇인가
- 받는 쪽이 개인인가: 강의료, 용역비, 경품이면 원천 공제 서식을 쓴다
- 수요일 정기 지급으로 되는가: 급하면 승인 단계가 늘어난다

## 이 가이드의 대상이 아닌 것

아래는 사전 승인 없이 처리하는 항목이다. 결제 수단과 정산은 [expenses.md](expenses.md)에 있다.

| 항목 | 처리 |
| --- | --- |
| 원팀 예산, 업무용 택시비, 오프라인 100만원 이하 업무비 | 고위드 카드 |
| 고위드 카드를 쓸 수 없는 오프라인 결제, 업무용 버스·지하철 | `법인 카드 반출 신청서` |
| 부득이하게 쓴 개인카드, 업무용 자가용 비용 | `예외적 지출-개인경비 지급 승인` |
| 저녁 식대, 심야 교통비 | 식대 카드, 카카오 T 비즈니스 |

| 고객·작가·창작자 환불과 보상 | `기타-환불/보상 지급 승인`. 아래 "환불과 보상" 참고 |

## 전체 흐름

| 단계 | 할 일 | 문서 |
| --- | --- | --- |
| 1 | 구매 검토. 견적을 받는다 | |
| 2 | 사전 승인을 받는다. 필요하면 계약서를 쓴다 | `사전 승인 요청`, `계약검토요청` |
| 3 | 주문하거나 발주한다 | |
| 4 | 물건을 받거나 서비스가 끝난 것을 확인한다 | |
| 5 | 자금집행 승인을 받는다 | `자금집행_국내이체` 등 |
| 6 | 재무회계셀이 지급한다 | |

결재 서식은 flex 워크플로우에서 작성한다. 2027년 1월 예정으로 friends-erp로 옮겨 간다. [friends-erp.md](friends-erp.md) 참고.

## 1. 사전 승인 요청

[`사전 승인 요청` 작성](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=f1ff655d462a4e17b463b49ce5501315)

적는 순서
1. 요청제목과 요청내용을 쓴다. 예: "신규 입사자 노트북 구입 검토의 건"
2. 지출구분을 고른다. 아래 표의 일반업무비, 마케팅비용, 상품제작·매입 중 하나다.
3. 거래시작일과 거래종료일을 넣는다. 한 번 사는 것이면 둘 다 납품 예정일이다. 정기 이용이면 이용 개시일과 종료일이다.
4. 거래 예정금액을 넣는다. 아래 "금액을 계산하는 법"을 따른다.
5. 비교 견적, 업체 제안서, 계약서 초안을 첨부한다. 논의한 노션·슬랙 링크는 메모에 넣는다.
6. 결재선을 아래 표대로 맞춘다. 1단계 참조에 재무회계셀을 넣는다.

금액을 계산하는 법
- 한 번 사는 것: 그 거래의 총 지출금액
- 정기 지출, 이용 기간 1년 이상: 1년으로 환산한 금액(월 지급액 × 12개월). 예: 2년간 월 100만원이면 1,200만원
- 정기 지출, 이용 기간 1년 미만: 그 기간의 총 이용금액. 예: 6개월간 월 100만원이면 600만원
- 외화 거래: 원화로 환산해 적고 외화 종류와 금액을 함께 적는다. 결재선은 원화 환산 금액으로 정한다

사전 승인 결재선 (2026-01-01 시행 기준)

| 지출구분 | 해당하는 것 | 금액별 결재선 |
| --- | --- | --- |
| 일반업무비 | 임차료, 소모품, 각종 서비스 이용료 등. 마케팅비용과 상품제작·매입이 아닌 지출 전부 | 500만원 이하: 셀리더<br>1,000만원 이하: 셀리더 → 유닛리더<br>3,000만원 이하: 셀리더 → 유닛리더 → C-Suite<br>3,000만원 초과: 셀리더 → 유닛리더 → C-Suite → CEO |
| 마케팅비용 | 국내·해외 광고비, 경품 등 판촉비, 창작지원금 등 | 1,000만원 이하: 셀리더 (유닛리더, C-Suite, CEO 참조)<br>3,000만원 이하: 셀리더 → 유닛리더 (C-Suite, CEO 참조)<br>5,000만원 이하: 셀리더 → 유닛리더 → C-Suite (CEO 참조)<br>5,000만원 초과: 셀리더 → 유닛리더 → C-Suite → CEO |
| 상품제작·매입 | 텐바이텐 PB·ODM 상품 제작, 텐바이텐 MD 상품 매입 | 1억원 이하: Admin 품의서. 셀리더 → 재무리더 → 유닛리더 (CEO 참조)<br>1억원 초과: flex `사전 승인 요청`(셀리더 → 유닛리더 → CEO)을 먼저 받고, 승인 문서를 PDF로 바꿔 Admin 품의서에 첨부한다 |

- 용역비처럼 원천 공제가 필요한 지출은 프렌즈셀 급여 담당자를 참조에 넣는다.

## 2. 계약서

- 꼭 써야 하는 경우: 거래 기간이 1개월 이상이거나 유지보수 조건이 필요한 거래
- 생략할 수 있는 경우: 연간 거래금액이 100만원 이하
- 돈이 나가지 않아도 법무 리스크가 있는 계약(업무 제휴, 개인정보 동의, 입점 계약 등)은 법무셀 가이드를 따른다.

계약 검토는 결재 서식 `계약검토요청`으로 올린다.
- 제목 형식: `계약검토요청_문서명_계약상대방명`
- 사전 승인 문서가 있으면 그 문서의 참조에 법무셀을 추가한다.
- 이 서식 하나로 계약 검토와 인감 날인까지 진행된다. 계약서가 아닌 문서에 날인이 필요하면 `인감날인요청(공문 포함)`을 쓴다.
- 첨부: 사업자등록증, 견적서(발주서), 계약서 초안. 상대가 개인이면 성명만 적고 신분증은 첨부하지 않는다.
- 문의: `#g_cell_legal`

## 3. 자금집행 승인

물건을 받았거나 서비스가 끝난 뒤에 올린다. 지급 방식에 맞는 서식을 고른다.

| 지급 방식 | 서식 | 꼭 넣을 것 |
| --- | --- | --- |
| 국내 계좌이체 | [`자금집행_국내이체`](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=d2acd05e47e845f3933bc5accbe5ebbf) | 거래처명, 이체금액, 은행명·계좌번호·예금주. 첨부: 세금계산서, 계약서, 견적서, 사업자등록증, 통장사본 |
| 개인에게 지급(강의료, 용역비, 경품) | [`자금집행_국내이체 (원천 공제)`](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=8e5a020abbf14f01a5bfa80893834ca6) | 신분증과 같은 성명, 소득 구분. 아래 "개인에게 지급할 때" 참고 |
| 해외 송금 | [`자금집행_해외이체`](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=57553bfdee5744fa98d06dc4d159e47f) | SWIFT CODE, 계좌번호, 인보이스에 적힌 수취인명, 송금 통화. 영문 인보이스 첨부는 필수다 |
| 온라인 카드결제 | [`자금집행_카드결제`](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=c5227a7e70844e739cd5a1bde1d7c9ab) | 수취인과 연락처, 배송지, 결제금액. 본문에 온라인 주문 내역(상세 페이지 정보)을 표로 정리한다. 재무회계셀이 결제한다 |

공통으로 할 것
1. `사전 승인 문서` 칸에서 승인이 끝난 `사전 승인 요청` 문서를 검색해 고른다. 문서번호나 제목으로 찾는다.
2. 지급형태를 고른다. 지급 요청일이 수요일이면 `정기`, 그 외 날짜면 `긴급`이다.
3. 지급 요청일자를 넣는다.
4. 증빙을 첨부한다.

자금집행 결재선
- 정기 지급: 재무회계셀 → 재무리더. 금액과 무관하다. 사전 승인 문서의 결재자들을 참조에 넣는다.
- 긴급 지급: 셀리더 → C-Suite 또는 유닛리더 → 재무회계셀 → 재무리더
- 문서에 고정돼 있는 결재선(재무회계셀 등)은 고치지 않는다.
- 상품제작·매입은 Admin 시스템이 재무리더로 자동 설정한다.

리더가 승인할 때 확인하는 것
- 사전 승인과 계약서가 필요한 건인지, 끝났는지
- 사전 승인 내용과 자금집행 요청 내용이 같은지
- 물건이 납품됐거나 서비스를 쓸 수 있는 상태인지. 먼저 지급해야 하면 그 사유

## 지급일

| 구분 | 지급일 | 기준 |
| --- | --- | --- |
| 계좌이체, 정기 | 매주 수요일 | 전주 수요일부터 이번 주 화요일까지 요청한 건을 이번 주 수요일에 지급 |
| 계좌이체, 긴급 | 매일 수시 | 금액별 결재선과 별개로 유닛리더 또는 C-Suite 승인이 꼭 필요하다 |
| 긴급 지급의 예외 | | 계약상 지급일이 고정돼 있으면 수요일이 아니어도 유닛리더·C-Suite 승인이 면제된다. 그래도 가급적 계약상 지급일 전 가장 가까운 수요일에 나가도록 올린다 |
| 온라인 카드결제 | 매일 수시 | |

## 개인에게 지급할 때 (원천 공제)

`자금집행_국내이체 (원천 공제)`를 쓰는 경우
- 개인에게 5만원을 넘는 경품·당첨금·적립금을 줄 때. 현물과 현금 모두 해당한다
- 개인에게 5만원을 넘는 소득을 줄 때: 출연료, 강의료, 저작권 수익, 원고료, 프리랜서 용역비 등

순서
1. 처음이면 Notion [`제세공과금 프로세스 정리`](https://app.notion.com/p/e412a3187b0649e3bc51dd5b7ffe23bf)를 먼저 읽는다. 신고 대상인지 모호하면 `#project_원천징수세금`에 묻는다.
2. `사전 승인 요청`을 올린다. 참조에 프렌즈셀 담당자와 재무회계셀을 넣는다.
3. `자금집행_국내이체 (원천 공제)`를 올린다.
   - 정기 지급: 프렌즈셀 담당자 → 재무회계셀 → 재무리더
   - 긴급 지급: 셀리더 → C-Suite 또는 유닛리더 → 프렌즈셀 담당자 → 재무회계셀 → 재무리더
4. 신고 대상이 10건 이상이면 Notion 문서에 있는 `소득신고 공통 양식` 시트를 작성해 프렌즈셀 담당자에게 따로 전달한다.

- 프렌즈셀 담당자 이름은 서식 안내문과 Notion 문서에 있다.
- 국외 법인에 지급하는 원천소득은 세율 증빙 자료를 꼭 첨부한다.

## 자주 막히는 곳

| 증상 | 조치 |
| --- | --- |
| 자금집행 금액이 사전 승인 금액보다 커졌다 | 사전 승인 문서를 다시 작성한다 |
| 급하지 않은데 `긴급`으로 올렸다 | 이번 주나 다음 주 수요일 정기 지급으로 바꾼다. 긴급은 정말 급할 때만 쓴다 |
| 온라인 예매나 구매를 해야 한다 | `사전 승인 요청`을 먼저 받고 `자금집행_카드결제`에 승인 문서를 연결한다 |
| 결제 사이트가 개인 계정으로만 결제된다 | 결제하기 전에 재무회계셀 카드결제 담당에게 확인한다. 이미 개인카드로 냈다면 `예외적 지출-개인경비 지급 승인`으로 정산한다 |
| 현장에서만 살 수 있다 | 셀 리더가 관리하는 고위드 카드로 결제한다. [expenses.md](expenses.md) |
| 개인에게 주는 돈인데 `자금집행_국내이체`로 올렸다 | 5만원을 넘는 경품이나 소득이면 원천 공제 서식으로 다시 올린다 |
| 증빙이 부족하다는 답을 받았다 | 무엇을 샀는지와 함께 결제 내역(결제일시, 가맹점)을 알 수 있는 자료를 더한다 |

## 문의

- 사전 승인, 자금집행, 지급 일정, 카드결제: 재무회계셀. 채널은 `#g_cell_account`
- 원천 공제와 제세공과금: 프렌즈셀 급여 담당. 채널은 `#project_원천징수세금`
- 계약 검토와 날인: 법무셀. 채널은 `#g_cell_legal`

## 확인이 필요한 것

- 사전 승인이 필요 없는 최소 금액이 있는지는 문서에 없다. 가이드는 고위드 카드로 내는 "오프라인 100만원 이하 업무비"만 사전 승인 없는 항목으로 든다.
- 상품제작·매입에 쓰는 Admin 품의서의 위치와 작성법은 확인하지 못했다.
- 법무셀 가이드는 읽지 못했다. 계약 검토 내용은 결재 서식 안내문에서 확인한 것이다.
- 사전 승인부터 지급까지 걸리는 처리 기간은 문서에 없다.
- 채널에서는 비품이 필요할 때 "구매요청을 해 달라"며 이 가이드를 가리킨다. 총무 비품을 프렌즈셀에 요청하는 별도 절차가 있는지는 확인하지 못했다.
- 세금계산서 발행·수정 절차는 이 가이드에 넣지 않았다. 텀블벅용 `세금계산서 수정 발행 요청서` 서식만 확인했다.
