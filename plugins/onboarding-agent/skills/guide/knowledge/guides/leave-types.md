# 휴가 종류와 규칙

## 한 줄 요약

휴가는 휴가 신청 화면에서 종류를 골라 신청한다. 연차와 포상휴가를 뺀 대부분의 휴가는 **증빙 첨부가 필수**다.

## 어디서 신청하나

- 신청하는 순서와 증빙 첨부는 [leave-request.md](leave-request.md), 경조 휴가와 경조비는 [condolence.md](condolence.md)
- 지금: flex → 휴가. 화면 조작은 flex 공식 문서 [휴가 등록 및 내 휴가 관리](https://guide.flex.team/en/articles/10229315-registering-leave-and-managing-my-leave-on-flex-web)를 따른다. 연속된 날짜에 반차를 섞을 때는 「세부 일정 수정」에서 따로 지정해야 한다
- 2027년 1월 예정 전환 후: friends-erp → 메뉴 「휴가」 → 종류 카드 선택. [friends-erp.md](friends-erp.md) 참고

## 휴가 종류

friends-erp에 설정된 값이다. 한도는 연간 기준이다.

| 종류 | 연간 한도 | 증빙 | 비고 |
| --- | --- | --- | --- |
| 연차 | 보유한 만큼 | 불필요 | friends-erp에서는 결재선이 없어 신청 즉시 승인·차감된다 |
| 포상휴가 | 부여받은 만큼 | 불필요 | 관리자가 부여한다 |
| 가족돌봄 | 10일 | 필수 | [family-care-leave.md](family-care-leave.md) |
| 건강검진 반차 | 0.5일 | 필수 | |
| 공가 | 한도 없음 | 필수 | 예비군 등 |
| 병가 | 60일 | 필수 | 달력일 기준으로 센다(주말·공휴일 포함) |
| 난임 치료 | 6일 | 필수 | 병원에서 발급된 진단서(치료 기관명과 시술 예정일 포함) |
| 배우자출산 | 20일 | 필수 | 10일로 적은 문서도 있다([gaps.md](../gaps.md)) |
| 배우자 유산·사산 | 5일 | 필수 | 유산 또는 사산 사실을 증명하는 의료기관 진단서 |
| 결혼 - 본인 | 10일 | 필수 | |

| 조의 - 배우자/자녀 | 7일 | 필수 | |

| 조의 - 친형제자매 (배우자 포함) | 5일 | 필수 | |

| 조의 - 친형제자매의 배우자 | 3일 | 필수 | |

## 휴가 화면이 아니라 결재 서식으로 신청하는 것

- 출산 휴가: `출산 휴가 신청서`
- 육아휴직: `육아휴직 신청서`
- 그 밖의 휴직(가족 돌봄 휴직 포함): `일반휴직 신청서`. 신청 전에 리더, 프렌즈셀과 사전 협의가 필요하다
- 무급 병가: `무급 병가 신청`. 연차를 소진한 뒤 쓸 수 있다
- 연차를 초과해 써야 할 때: `유결 신청서`
- 경조비: `경조비 신청`. 경조 휴가와 별도로 신청한다
- 복직: `복직 신청서`

서식 목록은 [workflows.md](../workflows.md).

## 답할 때 주의

- **증빙이 "필수"라는 사실까지만 확인됐다.** 난임 치료와 배우자 유산·사산을 뺀 나머지는 어떤 서류를 내야 하는지 시스템에 안내문이 없다. 서류 종류를 추측해 말하지 않고 프렌즈셀(HR)에 확인하도록 안내한다.
- 휴가 승인 여부, 증빙 인정 여부는 HR이 판단한다.
- 유급인지 무급인지는 이 표에 없다. 가족돌봄휴가는 무급이라는 Notion 기록이 있다. 다른 종류는 확인이 필요하다.
- 배우자출산휴가는 Notion 문서 두 곳이 사용 기한과 분할 횟수를 다르게 적고 있다([gaps.md](../gaps.md)). 일수만 안내하고 기한과 분할은 HR 확인으로 연결한다.

## 확인이 필요한 것

- 위 값은 QA 기간 중인 friends-erp의 설정이다. 결혼, 조의, 건강검진 반차, 병가의 일수는 Notion 제도 문서와 같은 것을 확인했다. 지금 정식인 flex의 설정과는 대조하지 못했다.
- Notion `연차 외 휴가 정책`에만 있는 종류가 있다: 보건휴가(월 1일, 무급), 태아검진휴가, 장기근속휴가.
- 병가와 유결은 무급이고 하루 단위로만 쓴다. 경조 휴가는 나눠 쓸 수 없다. 자세한 내용은 [leave-request.md](leave-request.md)
- 조회한 계정이 신청할 수 있는 종류만 나온 목록이다. 사람에 따라 다른 종류가 더 있을 수 있다.
- 종류별 유급·무급, 사전 신청 기한, 결재선은 확인하지 못했다.
- 반차와 시간 단위 사용이 어느 종류에서 되는지 확인하지 못했다.
