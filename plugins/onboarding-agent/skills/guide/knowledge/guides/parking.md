# 주차

## 한 줄 요약

방문 차량은 **차가 주차장에 들어온 뒤** `#_qna_genie` 고정글의 주차등록봇으로 직접 등록한다(최대 2시간). 2시간이 넘거나 업무로 본인 차를 가져올 때는 프렌즈셀과 미리 협의한다. 출퇴근용 정기 주차는 분기마다 `#_talk` 공지의 구글 폼으로 신청하고, 유료다.

## 먼저 물어볼 것

- 누구 차인가: 방문객 차 / 업무 때문에 하루 가져오는 본인 차 / 매일 세울 본인 차(정기 주차)
- 얼마나 세우나: 2시간 이하 / 2시간 초과
- 차가 이미 주차장에 들어왔나: 들어오기 전에는 등록할 수 없다

## A. 방문 차량, 2시간 이하 (직접 등록)

1. 차가 건물 주차장에 **들어온 것을 확인한다**. 시스템이 입차한 차량만 찾기 때문에 미리 등록할 수 없다.
2. `#_qna_genie` 채널 상단의 고정글을 연다. [주차 등록 자동화 안내](https://backpackr-talk.slack.com/archives/C4UHULRPB/p1752571501498849)
3. 그 글에 달린 `:주차등록:` 이모지를 누른다. 채널에 `주차등록봇`이 나타난다.
4. 이름, 차량번호, 날짜를 입력하고 요청 시간을 고른다. 30분 단위로 고를 수 있다.
5. 고정글의 스레드에 봇 댓글로 결과가 달린다. 꼭 확인한다.
   - `무료주차 1시간이 등록되었습니다`, `무료주차 1시간, 유료주차 30분이 등록되었습니다` 같은 문구 → 등록됨
   - `검색 결과가 없습니다. 출차된 차량은 검색되지 않습니다` → 등록 안 됨. 아래 "자주 막히는 곳"을 본다.

## 지원 범위와 비용 (2026-11-17 기준)

| 항목 | 내용 |
| --- | --- |
| 지원 시간 | 방문객·업무 목적 주차는 최대 2시간 |
| 누가 내나 | 처음 1시간은 건물이 제공하는 무료 주차. 1시간을 넘는 시간은 회사가 부담하는 유료 주차 |
| 2시간 초과분 | 차를 가져온 사람이 부담하는 것이 원칙. 사유가 있으면 미리 프렌즈셀과 협의 |
| 무료 1시간 | 같은 차량에 하루 한 번만 적용된다. 오전과 오후에 두 번 들어와도 무료는 한 번이다 |
| 환불 | 등록 없이 나가서 낸 방문 주차 요금은 돌려받을 수 없다. 환불은 정기 주차만 가능하다 |

시간당 주차 요금은 문서에서 확인하지 못했다.

## B. 2시간 초과, 종일, 행사 차량

1. 미리 `#_qna_genie`에 올린다: 날짜, 목적, 차량 대수, 필요한 시간.
2. 프렌즈셀이 지원 여부와 시간을 답한다.
3. 당일 차가 들어온 뒤, 같은 스레드에 프렌즈셀을 태그하고 차량번호를 남긴다. 프렌즈셀이 등록한다.

행사로 여러 대가 올 때
- 차량번호를 모아 한 번에 전달하면 프렌즈셀이 일괄 등록한다.
- 입차한 차량만 조회되므로, 당일 현장에서 실제로 들어온 차량번호를 모아 전달한다.

## C. 업무 때문에 본인 차를 가져올 때

- 지원 대상: 짐이나 물품 이동이 많을 때, 이동 인원이 많을 때, 대중교통이 어려운 장거리 외근처럼 차량이 꼭 필요한 경우.
- 개인 용무는 지원하지 않는다. 외근은 대중교통이 원칙이다.

1. 미리 `#_qna_genie`에 차를 가져와야 하는 사유를 구체적으로 적어 협의한다.
2. 차가 들어온 뒤 스레드에 프렌즈셀을 태그한다. 프렌즈셀이 등록한다.

외근지에서 쓴 주차료·주유비·통행료(수도권에 한함)는 주차 등록이 아니라 비용 처리다. flex [예외적 지출-개인경비 지급](https://flex.team/workflow/archive/my?workflow-action=create&workflow-template-key=538895abf04540d5b03623e8786b74bd) 서식에 주차료 영수증과 네이버 경로 검색 금액을 첨부한다. 결재는 2027년 1월 예정으로 friends-erp로 옮겨 간다([friends-erp.md](friends-erp.md)).

## D. 정기 주차 (매일 세우는 본인 차)

신청
1. 분기가 시작되기 약 일주일 전, 프렌즈셀이 `#_talk`에 「정기 주차 신청 안내」를 올린다. 예: [2026년 9~11월 분기 공지](https://backpackr-talk.slack.com/archives/C4UJHLN2X/p1787539163915539)
2. 공지에 있는 [주차 신청서(구글 폼)](https://forms.gle/We7En4cncK2jTPSR7)를 작성한다. 2026년 2·5·8월 공지 모두 같은 폼 주소였다.
3. 접수 마감일에 결과가 같은 공지의 스레드로 나온다. 2026년에는 세 번 모두 분기 시작 전 주 금요일 14시가 마감이었다.
4. 선정되면 안내된 기한까지 이용료를 무통장 입금한다. 입금 계좌는 결과 공지와 [Notion 원문](https://app.notion.com/p/3c65aa6d638e4cf4abb6d2e5850ca60d)에 있다. 여기에는 적지 않는다.

규칙 (2026-11-17 기준)

| 항목 | 내용 |
| --- | --- |
| 기간 | 3개월 단위. 12~2월, 3~5월, 6~8월, 9~11월 |
| 이용료 | 3개월 30만원(월 10만원) |
| 지원 대수 | Notion 문서는 총 7대. 분기 공지에는 12대(2026년 3~5월, 6~8월)와 7대(9~11월)로 안내됐다. 그 분기 공지를 따른다 |
| 선정 | 신청이 지원 대수를 넘으면 거리 비례 가점제로 추첨한다. 넘지 않으면 신청자 전원 지원 |
| 재신청 | 기존 이용자도 분기마다 다시 신청한다. 재당첨 제한은 없다 |
| 지정 주차 | 직선거리가 가장 먼 1명에게 지정 주차를 지원한다(분기 공지) |
| 추가 접수 | 남는 자리가 있으면 추가 신청을 받는다 |
| 업무상 정기 주차 | 허용하지 않는다. 업무로 하루 필요하면 위 C 절차를 따른다 |

환불, 양도, 차량 변경
- 확정 뒤에는 환불이 원칙적으로 안 된다. 중도 퇴직하면 퇴직일까지 일할 계산해 돌려준다.
- 주거지 이전, 장기 부재(병가, 휴직, 장기 휴가, 장기 출장 등), 그 밖의 업무상 이유로 2주 이상 이용이 어려우면 담당 부서 검토 후 예외로 환불할 수 있다.
- 임의로 양도할 수 없다. 필요하면 프렌즈셀 주차 담당과 협의한다.
- 차량을 바꾸거나 수리로 차량번호가 바뀌면, 바뀐 차가 들어오기 **하루 전(업무일 기준)까지** 프렌즈셀에 변경 후 차량번호, 차량 정보, 변경 기간을 알린다. `#_qna_genie`에 올리면 프렌즈셀이 처리한다.

## 자주 막히는 곳

- **`검색 결과가 없습니다`가 뜬다** → 차가 아직 들어오지 않았거나 이미 나간 경우다. 옆 건물에 세운 경우도 있다. 방문객에게 위치를 확인하고, 입차 뒤에 다시 등록한다.
- **미리 등록해 두고 싶다** → 안 된다. 입차 전에 넣은 등록은 실패로 처리된다.
- **등록했는데 주차 요금이 나왔다** → 봇 결과 댓글이 "등록되었습니다"였는지 본다. 이미 출차한 차량은 뒤늦게 등록하거나 환불할 수 없다.
- **시간을 잘못 골랐다, 같은 차를 두 번 등록했다** → `#_qna_genie`에서 프렌즈셀에 요청하면 시간을 고치거나 하나를 지워 준다.
- **봇으로 등록이 안 된다** → 고정글 스레드에 프렌즈셀을 태그한다.

## 문의

`#_qna_genie`에서 프렌즈셀.

## 확인이 필요한 것

- 봇 입력 화면을 직접 보지 못했다. 차량번호를 전체로 넣는지 뒤 네 자리만 넣는지, "이름" 칸에 누구 이름을 넣는지 확인하지 못했다. 봇 결과 댓글에는 차량번호가 숫자로만 남는다.
- 시간당 주차 요금과, 2시간을 넘긴 방문객이 요금을 어떻게 내는지는 문서에 없다.
- 다음 분기(2026년 12월~2027년 2월) 정기 주차 공지는 2026-11-17 현재 올라오지 않았다. 신청 폼 주소가 그대로인지 그 공지에서 확인해야 한다.
- 주차비 등록 답변의 원본 대화는 2024년 11월이다. 무료 1시간과 회사 부담 범위가 지금도 같은지 프렌즈셀 확인이 필요하다.
- 주말·공휴일 방문 주차가 평일과 같은지는 문서에 없다. 채널에서는 휴일에도 같은 방식(입차 후 프렌즈셀 태그)으로 처리됐다.
