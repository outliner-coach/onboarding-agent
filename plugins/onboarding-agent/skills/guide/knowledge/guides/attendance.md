# 근태

## 한 줄 요약

출퇴근, 휴게, 외근·출장은 **flex에서 본인이 직접 기록하고 고친다.** 결재 서식이 필요한 것은 휴일 근무(신청과 결과 두 번), 시차 출퇴근 예외, 예외 리모트 근무다.

근태는 2027년 1월 예정으로 flex에서 friends-erp로 옮겨 간다. 전환 전까지는 flex가 정식이다. [friends-erp.md](friends-erp.md) 참고.

## 먼저 물어볼 것

- **"시차"가 무엇을 뜻하는지 확인한다.** 회사에서 두 가지로 쓰인다.
  - 시차 출퇴근: 출근 시각을 정해진 범위 안에서 고르는 제도. 이 가이드에서 다룬다.
  - 시차(시간차): 시간 단위로 쓰는 휴가. [leave-request.md](leave-request.md)에서 다룬다.
- 기록을 고치려는 것이면 언제 근무분인지 묻는다. 오늘·어제 것과 그보다 지난 것은 절차가 다르다.

## 한눈에 보기

| 할 일 | 어디서 | 알아 둘 것 |
| --- | --- | --- |
| 출근·퇴근·휴게 기록 | flex 홈 위젯 또는 Slack의 flex 봇 | 퇴근할 때 확정까지 눌러야 한다 |
| 잘못 기록한 시간 수정 | flex → 「근무」 → 「내 근무」 | 근무를 종료한 뒤에 고친다. 워킹데이 기준 1일이 지난 기록은 조직장 승인이 필요하다 |
| 주 52시간에 닿아 등록이 안 됨 | 등록할 수 있는 최대치까지만 입력 | 넘는 시간은 등록하지 않는다. 출근 증빙도 따로 내지 않는다 |
| 핫워커 인정 시간 확인 | 베이스캠프의 「내 챌린지」 | 매일 아침 갱신된다 |
| 정규 출근 시각 밖으로 근무해야 함 | 결재 서식 `시차 출/퇴근 예외 신청` | 최대 3개월 |
| 휴일 근무 | 결재 서식 `휴일 근무 신청` → 근무 → `휴일 근무 결과` | 워킹데이 3일 전까지 신청. 수당 대신 대체 휴무 |
| 외근·출장 | flex에서 근무를 시작할 때 근무 유형 선택 | 조직장에게 알림이 간다 |
| 질병·사고로 출근이 불가능함 | 결재 서식 `예외 리모트 근무 신청` | 지금도 운영되는지 확인이 필요하다 (아래 참고) |

결재 서식은 [flex 워크플로우 작성 화면](https://flex.team/workflow/write/templates)에서 이름으로 검색한다. 목록은 [workflows.md](../workflows.md).

## 출퇴근 기록

기준
- 출근 시각은 **자리에 앉아 업무를 할 수 있게 된 시점**이다. 개인 용무로 업무 시작이 늦어지면 실제로 업무를 시작한 시각에 누른다.
- 퇴근 시각은 **자리를 떠나는 시점**이다.
- 엘리베이터홀이나 사무실 출입문을 지난 시각은 출퇴근 시각이 아니다.

순서
1. 출근하면 flex 홈 화면 왼쪽 위 위젯에서 근무 유형(근무, 출장 등)을 고르고 근무 시작을 누른다.
2. 저녁 식사 시간은 휴게로 등록한다. 방법은 두 가지다.
   - 근무 중: 오른쪽 위 「근무 중」 탭 → 일시정지 버튼 → 휴게 시간 선택
   - 업무를 마친 뒤: 「근무」 탭 → 근무 막대 바깥의 빈 곳을 더블클릭 → 근무 유형을 「휴게」로 바꾸고 시간 입력
3. 퇴근할 때 「확인 후 끝내기」를 누르고, 팝업이 뜨면 「이대로 확정」을 누른다.

알아 둘 것
- 저녁 식사는 휴게 등록이 원칙이다. 실제로 업무를 겸한 식사(워킹 디너)만 근무시간으로 인정된다. 밖에서 먹으면 이동 시간도 휴게다.
- Slack에 flex 봇을 추가하면 알림에서 한 번 눌러 출퇴근을 기록할 수 있다(Slack 왼쪽 위 메뉴 → More → Apps → flex 검색 → flex 봇 추가). 누른 시각이 그대로 기록된다.
- **자정이 넘으면 Slack 봇으로 퇴근 기록이 되지 않는다.** flex 웹에서 고친다.
- 구글 캘린더를 연동하면 근무·휴가 일정이 캘린더에 보인다. 캘린더에서 고치거나 지워도 flex에는 반영되지 않는다. 수정은 flex에서 한다.
- 화면 조작은 flex 공식 문서 [근무 등록 및 조회](https://guide.flex.team/en/articles/10294052-work-registration-and-viewing)를 따른다. 버튼 이름은 flex가 바뀌면 달라질 수 있다.

## 근무시간을 잘못 기록했을 때

출근을 늦게 눌렀거나, 퇴근을 안 누르고 나갔거나, 시각이 실제와 다를 때다.

1. 그날 근무가 아직 진행 중이면 먼저 근무를 종료한다. 프렌즈셀 안내가 "근무 종료 후 수정"이다.
2. flex → 「근무」 → 「내 근무」에서 해당 날짜의 근무를 눌러 시각을 실제대로 고친다.
3. 고친 날짜가 워킹데이 기준 1일을 넘게 지난 기록이면 조직장에게 승인 요청이 간다. 조직장이 flex 홈 피드의 「해야 할 일」에서 승인해야 반영된다.

알아 둘 것
- 출퇴근 시각을 바꾸면 조직장에게 알림이 간다. 이상이 있으면 조직장이 수정을 요청한다.
- 핫워커 챌린지 문서는 "근무 기록 수정은 해당 근무 다음 날까지 할 수 있다"고 적고 있다. 가능하면 다음 날 안에 고친다.
- 고친 시간이 베이스캠프의 핫워커 대시보드에 바로 보이지 않는 것은 정상이다. 대시보드는 매일 아침 갱신되므로 다음 날 반영된다.

## 주 52시간에 닿았을 때

flex는 법정 한도에 맞춰 운영된다. 한 주의 근무시간이 52시간에 닿으면 그 뒤 근무는 등록되지 않는다.

- 퇴근 시각은 flex가 허용하는 가장 늦은 시각으로 입력한다. 그 뒤 시간은 등록하지 않는다.
- 52시간이 이미 차서 남은 근무일에 출근 기록을 시작할 수 없어도, 그날 근무시간을 flex에 넣지 않아도 된다. 출근했다는 증빙도 따로 내지 않는다. 그 주 앞선 날짜에 52시간을 채운 사실이 flex에서 확인되기 때문이다. (2026-11-12 프렌즈셀 답변)
- 52시간을 넘겨 일해야 하는 상황 자체는 이 가이드가 판단할 수 없다. 리더와 프렌즈셀(HR)에 알린다.

## 핫워커 챌린지 인정 시간

핫워커 챌린지는 베타로 운영되는 제도다. 조건과 운영 여부가 바뀔 수 있다. 아래는 Notion `핫워커 챌린지(Beta) 세부기준 안내`(2026-10-06 수정)의 내용이다.

달성 조건은 챌린지 기간(매달 1일부터 말일) 동안 하루 평균 10시간 이상 근무다. 인정되는 시간은 아래와 같다.

| 구분 | 인정 기준 |
| --- | --- |
| 사무실 근무 | 공식 출근시간(9시 30분~10시 30분) 이후의 근무와 야간 연장근로. 공식 출근시간 전의 근무는 포함되지 않는다 |
| 외근, 출장 | 포함된다. 외근·출장한 날도 10시간 근무해야 한다. 사무실 복귀가 원칙이고, 어려우면 현장 근처에서 추가 근무할 수 있다 |
| 재택근무 | 포함되지 않는다 |
| 휴가 | 반차 이상 사용 시 5시간, 연차 사용 시 10시간이 인정된다. 반차보다 짧은 시간 단위 휴가는 인정되지 않는다 |
| 저녁 식사, 회식 | 저녁 식사는 휴게로 등록한다. 회식 시간은 따로 인정하지 않는다 |
| 유결 | 인정 시간에 포함되지 않는다 (2026-09-29 프렌즈셀 답변) |

- 한 달 동안 반차 이상 휴가를 합쳐 5일 넘게 쓰면 그달 참여 대상에서 빠진다. 근속포상 휴가도 포함해 센다.
- 제외 대상: 그달 초 기준 수습 중인 구성원, 경영진, 크루, 현장 근무자, 그달 중도 퇴사자.
- **52시간 때문에 금요일에 8시간을 등록하지 못한 경우** 그날 인정 시간은 8시간으로 자동 보정된다. 요청할 필요가 없다. 금요일에 8시간 넘게 일해도 인정은 8시간까지다. (프렌즈셀 답변)
- 내 인정 시간은 베이스캠프의 「내 챌린지」 메뉴에서 본다. 아는 것과 다르게 표시되면 `#_qna_genie`에 문의한다.
- 보너스 금액과 달성 여부는 이 가이드에서 답하지 않는다. 프렌즈셀이 판단한다.

## 시차 출퇴근과 예외 신청

- 공식 출근시간은 9시 30분~10시 30분이다. 이 범위 안에서 출근한다.
- 기본 근무시간 앞뒤로 붙여 연장근무를 할 수 있다(예: 07:30~18:30, 10:30~21:30). 다만 공식 출근시간 전의 근무는 핫워커 인정 시간에 들어가지 않는다.
- 지각은 원칙적으로 금지다. 지각했으면 보강근무로 약속된 근무시간을 채운다.
- 근무 중 개인 용무로 자리를 비울 때는 시간 단위 휴가를 쓰는 것이 기본이다. 아주 짧은 이석은 리더 승인 아래 유연하게 운영되기도 하지만 공식 정책은 아니다. (2026-08-25 프렌즈셀 답변)

정규 출근시간 밖으로 근무해야 할 때

| 상황 | 결재 서식 | 알아 둘 것 |
| --- | --- | --- |
| 업무상 불가피하게 정규 시차 출퇴근 시간 밖에 근무해야 함 | `시차 출/퇴근 예외 신청` | 아래 순서 참고 |
| 임신 중이거나 초등학교 입학 전 자녀를 키우며 주기적으로 출근 시각 조정이 필요함 | `임신/육아기 예외 시차 출,퇴근제 신청서` | 출근 가능 시간대 8시 30분~10시 30분. 반기 단위로 신청한다. 단발로 4일 이상 필요하면 「단기」를 고른다. 임신 확인서 또는 주민등록등본·가족관계 서류를 첨부한다. 육아기 단축 근로와 함께 쓸 수 없다. 2차 승인이 끝난 다음 날부터 적용된다 |

`시차 출/퇴근 예외 신청` 순서
1. 리더와 예외 적용 시간과 기간을 먼저 협의한다.
2. 서식을 작성한다. 신청 사유(업무상 필요성)를 구체적으로 쓴다. 기간은 최대 3개월이다.
3. 결재선을 확인한다. 승인 순서는 셀 리더 → 유닛 리더 → C-suite → HR이다. 유닛 리더가 있는 조직은 3단계에 C-suite 리더를 직접 추가한다.
4. 승인이 끝나면 flex의 근무 유형이 바뀐다. 누가 바꾸는지는 안내문에 없다.
5. 사유가 없어지면 바로 정규 근무로 돌아간다. 3개월을 넘겨 필요하면 다시 신청한다.

정기적으로 심야·새벽에 근무해야 하는 경우는 리더와 C-suite 승인을 받고 워크플로우에 등록한 뒤 프렌즈셀에 알린다고 안내돼 있다. 어느 서식인지는 문서에 없다. 프렌즈셀에 확인한다.

## 휴일 근무 신청과 결과 보고

인정 기준 (Notion `휴일근무/대체휴무 신청`, 2026-07-22 수정)
- 업무상 필요(오프라인 행사 등)하거나 회사가 요청해서 휴일에 4시간 이상 근무한 경우만 인정된다.
- 리더, 프렌즈셀 담당자와 사전 협의하지 않은 휴일 근무는 인정되지 않는다. 긴급 대응은 예외다.
- 평일에 끝내지 못한 업무를 보충하려는 휴일 근무는 인정이 어렵다.
- 사무실에 출근해서 한 근무만 인정된다. 재택근무는 인정되지 않는다.
- 수당 대신 대체 휴무를 받는다. 4시간 이상 근무하면 반차, 8시간 이상이면 하루다.

순서
1. 리더와 근무일, 근무 시간, 근무 내용, 대체 휴무 사용일을 협의한다.
2. 결재 서식 [`휴일 근무 신청`](https://flex.team/workflow/write/templates?template-key=e9c206a90546411a97277f47f8cf8660&im=write)을 올린다. **휴일 근무일 기준 워킹데이 3일 전까지** 올린다.
3. 리더와 HR 담당자가 승인한다.
4. 협의한 내용대로 근무한다.
5. 근무가 끝나면 결재 서식 [`휴일 근무 결과`](https://flex.team/workflow/write/templates?template-key=7e3ada9d542642b4937518e0976f97a9&im=write)를 올린다. 실제 근무일과 근무 시간(휴게 제외), 대체 휴무 사용 예정일, 실제 수행한 업무, 앞서 올린 신청서 링크를 넣는다.
6. 리더와 HR 담당자가 승인하면 HR이 대체 휴무를 부여한다. flex → 「휴가」 → 「휴가 등록」 → 「모두 보기」에서 확인한다.
7. 본인이 flex에서 대체 휴무를 직접 등록해 쓴다. 신청서에 적은 날에 쓴다.

대체 휴무 규칙
- 발생일부터 2주 안에 써야 한다. 안 쓰면 없어진다.
- 나눠 쓸 수 없다. 하루짜리를 반차 두 번으로 쓸 수 없다.
- 업무 때문에 사용일을 바꿔야 하면 HR 담당자에게 알린 뒤 등록한다.

## 외근·출장 등록

1. flex에서 근무를 시작할 때 근무 유형을 외근 또는 출장으로 고른다.
2. 등록하면 조직장에게 알림이 간다. 구글 캘린더를 연동해 두면 동료에게도 보인다.

알아 둘 것
- 외근을 위한 별도 결재 서식은 확인되지 않았다. 프렌즈셀 답변은 "근무 등록 시 외근으로 입력"이다.
- 외근·출장 비용은 근태와 별개다. 교통비와 정산은 [business-trip.md](business-trip.md), 결제 수단은 [expenses.md](expenses.md)를 본다. 결재 서식 `국내 출장 신청서`, `국내 출장 보고서`, `출장비 신청`을 언제 쓰는지는 문서에서 확인되지 않았다.

## 예외 리모트 근무

결재 서식 `예외 리모트 근무 신청`의 안내문은 아래와 같다.

- 대상: 질병이나 사고로 거동이 불가능해 리모트 근무가 불가피한 경우. 이에 준하는 다른 사유는 HR과 상의한다.
- 업무 몰입과 효율이 떨어진 상태라면 개인 휴가를 쓰는 것이 원칙이다.
- 사유 발생일부터 달력 기준 최대 1주일 단위로 신청한다. 더 필요하면 처음 승인받은 문서를 첨부해 다시 신청한다.
- 필수 첨부: 진단서, 소견서 같은 증빙. 선택 첨부: 상태를 확인할 수 있는 사진 등.

순서
1. 서식을 쓰기 전에 리더와 사유를 먼저 이야기한다. 리더가 없으면 HR 담당자와 이야기한다.
2. 리더가 동의하면 서식을 상세히 작성해 올린다.
3. 1단계 리더 승인이 나면 하루는 긴급 허용된다.
4. 2단계 HR 승인이 나면 신청한 기간 전체가 허용된다.

**주의.** 2025년 5월 근무제도 개편 FAQ는 "근무 공간은 사무실, 예외 없음"이라고 적고 있고, 이 제도를 설명하던 Notion 페이지는 Archive로 옮겨져 있다. 결재 서식은 남아 있지만 지금도 승인되는 제도인지는 확인하지 못했다. 신청하기 전에 리더와 프렌즈셀(HR)에 먼저 묻도록 안내한다. `코로나19 확진자 예외 리모트 근무 신청` 서식도 목록에 있으나 현행 여부를 확인하지 못했다.

## 자주 막히는 곳

| 증상 | 조치 |
| --- | --- |
| 퇴근을 누르지 않고 나왔다 | 다음 날 flex 「근무」 → 「내 근무」에서 실제 퇴근 시각으로 고친다 |
| 출근을 한참 뒤에 눌렀다 | 그날 근무를 종료한 뒤 「내 근무」에서 출근 시각을 고친다 |
| 자정 넘어 Slack 봇으로 퇴근이 안 눌린다 | 봇은 자정 이후 동작하지 않는다. flex 웹에서 입력한다 |
| 구글 캘린더에서 근무 일정을 지웠는데 flex에 남아 있다 | 캘린더 수정은 flex에 반영되지 않는다. flex에서 고친다 |
| 주 52시간이 차서 퇴근 시각이 실제보다 이르게만 선택된다 | 선택되는 가장 늦은 시각으로 입력한다. 넘는 시간은 등록하지 않는다 |
| 52시간이 차서 금요일에 출근 기록을 시작할 수 없다 | 등록하지 않아도 된다. 증빙도 내지 않는다. 핫워커 인정 시간은 8시간으로 자동 보정된다 |
| 근무시간을 고쳤는데 핫워커 대시보드가 그대로다 | 대시보드는 매일 아침 갱신된다. 다음 날 다시 본다 |
| 휴일 근무 사전 신청을 놓쳤다 | 프렌즈셀 담당자에게 문의한다. Notion에도 "기한을 지키지 못하면 별도 문의"로 적혀 있다. 인정 여부는 HR이 판단한다 |
| 지난주 근무 기록을 고쳤는데 반영이 안 된다 | 워킹데이 기준 1일이 지난 기록은 조직장 승인이 필요하다. 조직장에게 flex 「해야 할 일」을 확인해 달라고 한다 |

## 문의

- flex 사용법, 근태, 휴일 근무, 핫워커: `#_qna_genie`에 올리면 프렌즈셀(HR)이 답한다.
- 건강 문제처럼 공개하기 어려운 사정이 있으면 프렌즈셀 HR 담당자에게 DM으로 문의한다.
- 근무 인정 여부, 예외 승인 여부는 리더와 HR이 판단한다. 이 가이드는 신청 경로까지만 안내한다.

## 확인이 필요한 것

- 현행 근무제도를 설명하는 전사 페이지가 생활 백서에 없다. 공식 출근시간(9시 30분~10시 30분), 지각, 보강근무는 2025년 5월 FAQ와 핫워커 문서에서 가져왔다. 2025년 5월 FAQ의 "크런치 모드"(주 50시간 권장, 사무실 근무)가 지금도 공식 기준인지 확인하지 못했다.
- 개인 용무로 자리를 비울 때: 2025년 5월 FAQ는 "1시간 이내 개인 용무는 리더 재량으로 보강근무 가능"이라고 하고, 2026년 8월 프렌즈셀 답변은 "외출·이석·보강 정책은 없고 시간 단위 휴가가 기본"이라고 한다.
- 지난 근무 기록 수정: flex 사용 가이드는 "워킹데이 1일이 지난 기록은 조직장 승인", 핫워커 문서는 "다음 날까지 수정 가능"이라고 적는다. 이틀 넘게 지난 기록을 승인받아 고칠 수 있는지, 아예 막히는지는 확인하지 못했다.
- 진행 중인 근무의 출근 시각을 종료 전에 고칠 수 있는지는 확인하지 못했다. `#_qna_genie` 봇의 등록 답변은 "종료 전에는 수정되지 않는다"고 하지만 그 답변에는 틀렸다는 표시가 하나 달려 있다. 이 가이드는 프렌즈셀이 직접 답한 "근무 종료 후 수정"만 적었다.
- 예외 리모트 근무와 코로나19 예외 리모트 근무 서식이 지금도 쓰이는지 확인하지 못했다.
- 휴일 근무 사전 신청을 놓쳤을 때: `#_qna_genie` 봇의 등록 답변(2024-10 대화 기반)은 "프렌즈셀에 문의하면 신청·결과 문서를 당일 작성하는 것으로 확인 후 대체 휴무를 받을 수 있다"고 한다. 최근 HR의 직접 답변은 찾지 못했다.
- 2025년 5월 FAQ는 평일 근무시간이 부족할 때의 주말 근무(4시간 이상, Slack 셀 채널에 출퇴근 공유)도 언급한다. 이 근무는 대체 휴무가 나오는 "휴일 근무"와 다르다. flex에 어떻게 기록하는지는 문서에 없다.
- 외근과 출장을 flex에서 고를 때의 정확한 메뉴 이름, 사전에 등록할 수 있는지, 이미 시작한 근무의 유형을 나중에 바꿀 수 있는지는 확인하지 못했다. Notion 문서의 화면 캡처는 읽지 못했다.
- flex 공식 문서(guide.flex.team)는 이 세션에서 열리지 않았다. 링크한 문서는 [official-docs.md](../official-docs.md)에 이미 있는 것이다.
- 텐바이텐 조직에도 같은 근태 기준이 적용되는지 확인하지 못했다.
