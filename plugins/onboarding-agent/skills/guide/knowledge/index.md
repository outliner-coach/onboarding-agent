질문이 들어오면 이 표에서 주제를 찾고, 해당 가이드 파일만 읽는다.
표에 없는 주제는 [gaps.md](gaps.md)에서 알려진 공백인지 확인한다.

상태 값
- `문서확인`: Notion 원문에서 절차를 직접 확인함
- `부분확인`: 일부만 원문에서 확인됨. 빈 부분은 가이드 안에 표시
- `미확인`: 전사 표준 문서가 없음. 담당 셀 확인이 필요
